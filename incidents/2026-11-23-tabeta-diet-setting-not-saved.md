# たべたメモで、目的を「ダイエット」にしても体重を保つ目安が出ていた

- 種類: 操作の反応
- 場所: tabeta-memo（たべたメモ）の設定の画面
- 気づいた人: satou さん
- 影響: 目的を「体重を減らす」に変えても、きょうの画面は体重を保つ目安のままに見えた。

## 起きたこと
- 設定の目的・減らし方・身長・体重は、下の「この内容で目安を出す」を押したときだけ保存していた。押さずに「きょう」へ移ると、変えた内容は捨てられ、前の目安のままだった。
- 身長を m（1.6 など）で入れると、だまって「身長なし」にして、減量の目標を出さなかった。「早め」を BMI 25 未満で選ぶと、知らせずに体重を保つ目安にしていた。
- きょうの画面の目安の行が「体重を保つ目安 ○kcal から…」で始まり、減量の目安が文の後ろにあった。

## 原因
- 設定のフォームが「押して保存」の作りで、押さずに離れたときの扱いが無かった。範囲の外の値と選べない減らし方を、知らせずに捨てていた。

## なぜ見つからなかったか
- QA は毎回「目安を出す」を押してから「きょう」を見ていて、押さずに移る使い方を通していなかった。

## 対策
- [x] 直す: 設定は変えたらすぐ保存し「保存しました：1日の目安 ○kcal（減量）」を出す。身長・体重が範囲の外なら知らせて止める。BMI 25 未満では「早め」を選べなくする。目安の行は「減量の目安：1日 ○kcal」から始め、輪の横も「減量の目安」と書く（tabeta-memo #5）。
- [x] 防ぐ: tabeta-memo の `qa/run.mjs` に「押さずにきょうへ移っても減量の目安になる」「身長 1.6 は知らせる」「BMI 25 未満で早めを選べない」を足した（tabeta-memo #5）。
