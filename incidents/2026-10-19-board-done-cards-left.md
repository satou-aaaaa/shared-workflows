# 終わった作業のカードが、ボードで「済み」にならずに残っていた

- 種類: 見回りの見落とし
- 場所: TODO ボードと、その見回り（2時間ごと）
- 気づいた人: satou さん（「完了しているものが残っているようです」）
- 影響: 開いていたカード18枚のうち2枚（担当スレッドが終わった sandbox の Issue の件と、答えが出たカレンダーの確認）が、終わったあとも「Claude が対応中」「今やる」に残っていた。もう1枚（last-tell の CI 失敗）は「Claude が対応中」なのに担当がいなかった。

## 起きたこと
- 2026-10-19 夜、satou さんがボードに終わったカードが残っていると知らせた。
- 全カードを、担当スレッドの状態・PR と Issue の状態と突き合わせた。終わっていた2枚を済みにした。担当のいなかった1枚は、直すスレッドを立てるよう頼んだ。
- 確認の答えが出たのに、題が問いのまま残っていたカードも1枚あった。題を「やること」の形に直した。

## 原因
- カードを済みにするのは「作業したスレッドが自分で直す」ことに頼っていた。決まり（`routines/common.md`「約束は台帳に書く」）は、後の回へ回した約束のカードしか対象にしていなかった。確認カードと、ボードから AI に回したカードは対象外だった。
- 見回りは、返事待ちのカードを「足す」手順と、AI に「回す」手順しか持っていなかった。担当が終わったかを確かめて「閉じる」手順が無かった。

## なぜ見つからなかったか
- ボードのカードと、スレッド・PR・Issue の状態を突き合わせる検査が無かった。スレッドが resolve や completed になっても、ボードには何も伝わらなかった。

## 対策
- [x] 直す: 終わっていた2枚を済みにし、問いのまま残っていた1枚の題を直した。担当のいなかった last-tell の件は、直すスレッドを立てるよう頼んだ
- [x] 防ぐ: `routines/common.md` に「スレッドの仕事を終えるとき（resolve する前）に、そのスレッドが担当したボードのカードを済みにする」を足した（この PR）
- [x] 見つける: ボードの見回りに手順10「終わったカードを済みにする」を足した。2時間ごとに、全カードをスレッドの状態（resolved・completed）、PR・Issue の状態、確認の答えと突き合わせ、終わったものを済みにする。satou さんの操作だけ残るものは「今やる」に置き、題を「やること」の形に直す（「TODO のカンバン化」スレッド）
