# ベストを着る 3D の人の、V の上と肩ひもの縁に白いぎざぎざが見えていた

- 種類: 検査の見逃し
- 場所: last-tell-godot（3D キャラのスーツ：make_suit.py・bake_garment.py・character3d.gd・shirt.gdshader）
- 気づいた人: satou さん（第三部の 3D の見直し）
- 影響: ベストが一番外の 7 人（シオリ・ディーラー4・ディーラー3・タダシ・ディーラー5・ディーラー・ソウ）で、卓の並び・話すときの寄りの絵に、ベストの V の上・肩ひもの首寄りの縁に沿って白い切れ端が出ていた。ディーラーは毎場面映る。

## 起きたこと
- 2026-11-13 に、ベスト・上着の前の V と袖ぐりは「形を切ると焼いたときに縁が歯のようにぎざぎざになる」として、ゲームの描き分け（shirt.gdshader）に移した。
- 首の開きだけは make_suit.py の widen_neck・cap_top が面を丸ごと消して作るままだった。焼いて体に寄せると縁が階段になり、その外に下のシャツが白く見えた。
- 2026-11-20 に直しを始めたとき、最初の見立て（シャツがベストの前へ突き抜けている）で深さの寄せを入れたが、寄せても白い切れ端は消えなかった。ゲームの中だけで後から切る・ならす直しも 5 通り試したが、肩ひもが短くなるか、切った線が波打った。

## 原因
- V・袖ぐりを描き分けに移したときに、同じ理由で崩れる首の開きが「形で切る」側に残った。形で切る所と描き分ける所が混ざっていた。
- 焼いた後の形には、型の位置（式が成り立つ位置）が残らないので、ゲームの中では首の開きを式で切れなかった。

## なぜ見つからなかったか
- スーツの検査（check_suit_layers.gd：重なりの穴・肩の肌、bake_garment.py の suit_neck_check・suit_vest_check）は、どれも「布があるか・高さ・離れ」を見ていて、見える縁の形（ぎざぎざ）は見ていなかった。
- 最初の調べで「突き抜け」を前提に検査を作ったので、検査は通るのに見た目が変わらない時間が長かった。前提を絵で確かめる（色分けで、どの部品のどの切り方が縁を作っているか）のが遅れた。

## 対策
- [x] 直す: make_suit.py が頂点ごとに首の開きの式の値を書き、bake_garment.py が焼いた形の頂点へ運び（焼きは中点を後ろに足すだけで順が同じ）、bin_to_res.gd が形の meta "hole" に入れ、shirt.gdshader が値で描き分ける。ベストを着る 9 人を焼き直した（satou-aaaaa/last-tell-godot#168、chars3d-assets-vest1120a.zip・vest1120b.zip）
- [x] 防ぐ: 形で切るのは見えない所だけ（値が少し＋の所）にして、焼いた形の縁がいつも描かない所に入るようにした。bake_garment.py の首まわりの検査は見える所だけを見る（satou-aaaaa/last-tell-godot#168 の `game/chars/_tools/hair/bake_garment.py`）
- [x] 見つける: check_suit_layers.gd に「首の開きの見える縁」を足した：ベストが一番外の人は、ベストの形の首の開きの縁の頂点がみな描かない側か。直す前の形では ❌（値が無い）、直した後 ✅ を確かめた（satou-aaaaa/last-tell-godot#168 の `game/tests/check_suit_layers.gd`）
- [x] 見つける: check_suit_poke.gd：卓に座らせて前・左右から撮り、外の部品のすぐ前に写る内の布を数える。塗りが写るかも見る（寄せを POSITION に書いたとき opengl3 で描き分けが黙って全部消えたのを、この確かめで見つけた）（satou-aaaaa/last-tell-godot#168 の `game/tests/check_suit_poke.gd`、qa.sh に追加）
