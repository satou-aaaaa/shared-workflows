# 公開済みの「防災の判断」と同じ題材の新作を、ローマ字ちがいの名前で作りかけた

- 種類: 手順の抜け
- 場所: routines/game-dev.md 手順A の1・shared-workflows の Create repo
- 気づいた人: スレッド「防災の判断ゲームを作る」（画面のワナ探しの次）
- 影響: 2026-11-07 に1回。公開済みの bousai-handan（防災の判断）と同じ題材の bosai-handan を作り、Create repo で空のリポジトリ（README だけ）ができた。公開・一覧への追加の前に気づいたので、遊ぶ人への影響は無い。本体を作った約1時間がむだになった。

## 起きたこと
- プロジェクトのメモリ game-queue では「防災の判断」に担当が書かれていなかったため、まだだれも作っていないと思い、作り始めた。coordinator にも「重なりなし」と言われた。
- repos.txt は `grep -i "bosai\|saigai\|hinan\|jishin"` で探した。公開済みのリポジトリの名前は `bousai-handan` で、引っかからなかった。
- 一覧へ足す PR を作るときに repos.txt を開き、`bousai-handan` に気づいた。

## 原因
- 題材の重なりを、リポジトリ名のローマ字と、手で書くメモリだけで確かめていた。ローマ字の長音の書き方（bousai / bosai）は人によって揺れる。題材の正の一覧（project-practices.md のゲームの表。日本語の題名と中身がある）を見る手順が無かった。
- Create repo は同じ名前しか止めず、書き方ちがいの似た名前を止めなかった。

## なぜ見つからなかったか
- 手順A の1は「案を3つ出す」だけで、もう有る題材を探す場所と探し方を決めていなかった。メモリの game-queue は、作ったスレッドが書き忘れると抜ける。

## 対策
- [x] 直す: 作りかけた bosai-handan は公開せず、一覧にも足さない。空のリポジトリを消すかどうかは satou さんに聞く（消すのは取り消せないため）
- [x] 防ぐ: Create repo が、長音とハイフンをそろえた名前（ou→o・uu→u など）で、似た名前のリポジトリがあれば止める（`similar_ok` を付けたときだけ作る）（この PR）
- [x] 防ぐ: routines/game-dev.md 手順A の1に「project-practices.md のゲームの表を日本語の題材で探す。メモリに無くても表にあれば作らない」を足した（この PR）
