# 2段目「なぜ？」のヒントが、もうまちがえた分け方を選んで消し、★だけ減って何も消えなかった

- 種類: 動作
- 場所: satou-aaaaa/kokoku-minuki・kenko-minuki・gurafu-minuki の `index.html`（`cut2Of`・`hint`）
- 気づいた人: kenko-minuki #7 の CodeRabbit
- 影響: 2段目で先に1つまちがえてからヒントを押すと、★が1つ減るのに選び肢が1つも消えなかった。kokoku-minuki は公開済み（11/11 〜 直すまで）。記録が壊れることは無い。

## 起きたこと
- 2段目のヒントは「ちがう分け方を1つ消す」。消す先は `GK.filter((x) => x !== 正解)[0]`（正解でない最初の1つ）に決め打ちしていた。
- 先にその最初の1つを選んでまちがえる（`cur.w2` に入る）と、ヒントが同じものを「消す」ので、見た目は何も変わらず、ヒントの数だけ増えた。

## 原因
- 消す先を、もう ✕ になっている分け方（`cur.w2`）を除かずに決めていた。1段目のヒントには「まちがいの数で消す先を変えない」決まりがあり、それに合わせたつもりで、逆に「もう消えている物を選ばない」を落とした。

## なぜ見つからなかったか
- QA は「2段目でまちがえる → ヒント」を通していたが、まちがえる分け方も「正解でない最初の1つ」で、ちょうど消す先と同じだった。見ていたのは「消えた数が1以上」だけで、「ヒントで新しく1つ消えたか」を見ていなかった。

## 対策
- [x] 直す: 消す先を「正解でなく、まだまちがえていない分け方」の最初の1つにし、残りが無いときはヒントを押せなくした（kokoku-minuki・kenko-minuki #7・gurafu-minuki #7）
- [x] 防ぐ: drift-check に `depth:hint2` を足した。`cut2Of`（と、それが呼ぶ `…Of`）が `w2` を見ないと全ゲームの週の点検で出る（`scripts/game-patterns.mjs`・`scripts/check-game-patterns.mjs`、この PR）
- [x] 防ぐ: 3本の QA に「まちがえた分け方とは別のを消す（押せるのは正解だけ）」を足した。`routines/game-dev.md`「1問を深くする」に決まりを1行足した（この PR）
