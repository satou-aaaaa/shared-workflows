# 新しいゲームで、練習を始めると今日の途中経過が消え、古いタブで答えを二重に入れられた

- 種類: 動作
- 場所: kasane-zome・rosen-hitofude・seiza-tsunagi（どれも公開前）
- 気づいた人: CodeRabbit（kasane-zome #1 のレビュー）
- 影響: 公開前に見つけたので、遊ぶ人には出ていない。出ていれば「今日の5色」を途中まで進めて練習を開くと途中経過が消え、やり直しで結果を選び直せた。上級で「見本を覚えた」あとに開き直すと見本がまた見えた。同じ日を2つのタブで開くと1問目の答えが2つ入り、2問目を飛ばした。

## 起きたこと
- 2026-11-03 新しいゲーム3本を同じ形で作った。途中経過は1つの置き場所（`s.run`）に、今日・上級・練習のどれも入れていた。
- kasane-zome #1 に CodeRabbit が「練習で今日の進行が消える」「上級の隠した見本が戻る」「別タブの古い答えを足す」を指摘した。
- 同じ作りの rosen-hitofude・seiza-tsunagi にも同じ穴があった（指摘の前に直した）。

## 原因
- 途中経過をモードで分けずに1か所に置いた。練習を始めると今日の分を上書きする。
- 答えを入れるとき、保存されている進み具合が画面に出ている問題と同じかを見ていなかった（記録の読み直しはしていたが、何問目かは比べていなかった）。
- 上級の「覚えた」を画面の中だけに持ち、保存していなかった。

## なぜ見つからなかったか
- QA は「今日を最後まで」「練習を最後まで」を別々に通すだけで、「今日の途中→練習→今日に戻る」や2つのタブの順番を通していなかった。
- 既にあるゲーム（kabu-news は `cur`・`hcur` を分け、練習は保存しない）の作りを手本にせず、新しく書いた。
