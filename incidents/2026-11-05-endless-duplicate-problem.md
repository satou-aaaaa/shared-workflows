# とことんで、1回の中に同じ問題が2つ出ることがあった（しりとり最短）

- 種類: 検査の見逃し
- 場所: satou-aaaaa/shiritori-saitan index.html の endlessList・qa/run.mjs
- 気づいた人: CI の QA（PR #9 で1回だけ落ちた）
- 影響: とことんの60問の中に、出発と目的が同じ問題がまれに2つ出ていた（3000回作って3回）

## 起きたこと
- 関係のない PR の QA が「とことんの問題（5回分）：1回の中で同じ問題が出ず」で落ちた。手元で3000回作ると3回重なった。

## 原因
- endlessList が種をばらばらに引くだけで、できた問題が前と重なっていないかを見ていなかった。

## なぜ見つからなかったか
- 検査が5回分しか作っておらず、0.1%ほどで起きる重なりはほとんど当たらなかった。

## 対策
- [x] 直す: 重なったら種を引き直す（shiritori-saitan PR #9）
- [x] 見つける: QA を200回分に増やした（shiritori-saitan PR #9 の `qa/run.mjs`）
