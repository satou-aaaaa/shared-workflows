# うそつき六法：幅320pxのスマホで、答えたあとの「次のページへ」が画面の下に隠れるページが46あった

- 種類: 動作
- 場所: usotsuki-roppo（`index.html` の答え合わせの画面・`qa/run.mjs`）
- 気づいた人: 一括で直すスレッド（ひな形を配る PR #33 の QA がこの検査で落ちた）
- 影響: 320×640 の画面で、60ページ×（直した・逃がした）の120通りのうち46通りで「次のページへ」が画面の外にあり、下へずらさないと押せなかった。390px 幅では起きない。

## 起きたこと
- 11/17 夜、ひな形を配る PR（中身は QA の写し3行だけ）の QA が「320×640：答えると、答え合わせ（#res）と次へのボタンが画面の中に出る」で落ちた。
- 調べると、答え合わせの説明が長いページ（憲法の巻の ken9 など）では、答えたあと「次のページへ」が画面の下に出ていた。

## 原因
- 答え合わせの画面は、答える前と同じ位置のまま描き直すだけで、「次へ」が見えるところまで下げていなかった。

## なぜ見つからなかったか
- QA はこの見た目を、乱数で並べた最初の1ページ（憲法の巻・直したときだけ）でしか見ていなかった。長いページを引いたときだけ落ちるので、たまに赤になっても「ときどき落ちる検査」に見え、どのページかが出ていなかった。

## 対策
- [x] 直す: 答えたら「次へ」の下まで画面を下げる（動き（transform）の途中でもずれない offsetTop で測る）。usotsuki-roppo の PR（`index.html`・sw.js の CACHE を v13）
- [x] 見つける: QA が全60ページを、直したときと逃がしたときの両方で 320×640 に出して、動きを終えた位置で「次へ」が画面の中にあるかを見る（同じ PR の `qa/run.mjs`）。直す前は46通りを出し、直したあとは0
- [x] 防ぐ: `routines/game-dev-detail.md` の QA の行に「画面に入るか・はみ出すかの見た目の検査は、乱数で選んだ1問でなく全部の問題で見る」を足した（この PR）
