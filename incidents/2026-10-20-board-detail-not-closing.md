# ボードのカードの詳細を開くと、閉じられなくなった

- 種類: 見た目の不具合（検査の見逃し）
- 場所: claude.ai の TODO ボード（「TODO のカンバン化」スレッド）
- 気づいた人: satou さん
- 影響: 2026-10-20 の夜、PC でカードの詳細を開くと、閉じても画面に残った。うしろのカードも押せなかった（v46〜v48 の約30分）。

## 起きたこと
- v46 で「PC では詳細を広く2列で出す」を入れた。`#detail.wide{display:grid}` と書いた。
- 閉じた dialog はブラウザの決まり（`dialog:not([open]){display:none}`）で消える。この書き方はその決まりを上書きしていた。そのため、閉じても画面に出たままになった。
- あわせて、中身が長いカードでは下の「閉じる」が画面の外に出ていた。

## 原因
- `display` を、開いているとき（`[open]`）に限らずに当てた。
- 「閉じる」ボタンが中身のいちばん下にしか無かった。

## なぜ見つからなかったか
- 検査は「詳細の dialog の open が false になったか」だけを見ていた。画面から本当に消えたか、うしろが押せるかは見ていなかった。
- 基本の使い方（開く→閉じる→ほかを開く）を人の順に通す検査が無かった。機能ごとの検査だけだった。
- ボードの元が共有フォルダにしか無く、PR と CI を通さずに公開できた。

## 対策
- [x] 直す: `#detail.wide[open]` のときだけ grid にした。✕ をいつも右上に置き、下の「閉じる」は下に固定した。外を押しても閉じる（v49、2026-10-20）。
- [x] 見つける: `check-basics.mjs` を作った（ops-backup `board-src/qa/`）。基本の使い方を人が押す順に全部試す。開く・4通りで閉じる・閉じたら画面から消えてほかのカードが押せる・足す・移す・済み・コメント・下書き・答える・絞る・探す・見かたを、PC 2幅とスマホで回す。v48 で ❌、v49 で ✓ を確かめた。
- [x] 防ぐ: ボードの元を ops-backup の `board-src/` に置き、CI「Board QA」で4つの検査（基本・切り替え・スマホ・速さ）を回す。CI が赤いものは公開しない。機能を足す・直すたびに、その使い方のテストも足す（共有フォルダ `board/improve.md` の 3）。
