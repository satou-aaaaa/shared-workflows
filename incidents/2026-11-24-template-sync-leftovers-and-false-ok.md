# Template sync が45分で切り上げた残り22本に、直したひな形が届かず QA が落ちたままだった

- 種類: 公開・CI
- 場所: `.github/workflows/template-sync.yml`（各ゲームへ配る）
- 気づいた人: 見回り（tenji-yomi の ci-failure の Issue #17。2026-11-24）
- 影響: tenji-yomi の main の QA が 11/23 から赤のまま（「Aa が二重」の揺れ。直しは #596 で出ていた）。teko-tsuriai から先の22本に #596・#597 のひな形が届いていなかった。

## 起きたこと
- #596（11/23 11:24 UTC）の push の回は、待っているあいだに #597 が入ったので、手元のひな形が古いと sync-template.mjs が 3 で止まった。止まったのを `|| true` で隠し、全部のゲームに「ひな形どおり」と出した。
- 次の #597 の回は全部に配り始めたが、45分で切り上げ、teko-tsuriai から先は「次の回に回す」とした。3時間ごとの回はマージだけで配らないので、次に配るのは週1（11/30）だった。

## 原因
- 写す道具が止まったのを `|| true` で「ちがいなし」と同じに扱っていた。
- 切り上げた残りを拾う回が、実際には週1しか無かった（コメントの「次の回が拾う」とずれていた）。ゲームが 203 本に増え、1回が45分を超えるようになった。

## なぜ見つからなかったか
- 切り上げは ::warning で出るだけで、Issue にも見回りにも上がらなかった。「ひな形どおり」はうその成功で、ログを読まないと分からなかった。

- [x] 直す: 写す道具の失敗は「写す道具が止まった」と出して失敗に数える。3（ひな形が古い）のときは最新の main のひな形に替えて続ける。この PR
