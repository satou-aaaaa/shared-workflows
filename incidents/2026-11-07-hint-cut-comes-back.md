# ヒント2で消した選び肢が、まちがいを選ぶと戻ってきた

- 種類: 検査の見逃し
- 場所: 4択で「ヒント2：2つにしぼる」があるゲーム（裁判員のしくみ・健康情報みぬき・伝統工芸・元素記号・人体のしくみ など同じ作りのもの）
- 気づいた人: saibanin-shikumi #1 の CodeRabbit
- 影響: ヒント2で2つにしぼったあと、残ったまちがいを選ぶと、消したはずの選び肢が1つ戻ってきた（3つから選び直しになる）。次の問題へ進むとフォーカスが body に戻り、キーボード・読み上げで続けにくかった。

## 起きたこと
- 2026-11-07、saibanin-shikumi #1 で CodeRabbit が、`cutOf` が `cur.wrong` を除いてから消す選び肢を決めているため、まちがいが1つ増えると消す数が1つ減ると指摘した。
- 同じ `cutOf` を中身で探すと、ほかのゲームにも同じ作りがあった（同じ見本から写していた）。

## 原因
- `cutOf` が「まだ選んでいないまちがい」から消す数を決めていた。しぼったあとにまちがいを選ぶと、消す対象が減り、消していた1つが表に戻る。
- 画面を `innerHTML` で作り直したあと、フォーカスの行き先を決めていなかった。

## なぜ見つからなかったか
- 各ゲームの QA は「ヒント2で2つ消える」までしか見ず、そのあとにまちがいを選ぶ場合を作っていなかった。
- 写して広がった作りを、まとめて見る所が無かった。

## 対策
- [x] 直す: 消すのを「正解でない選び肢のうち最後の1つ以外」に固定し（まちがいの数で変えない）、次の問題で問題の枠にフォーカスを移した。QA に「ヒント2のあとに残ったまちがいを選ぶと正解だけが残る」「次の問題でフォーカスが問題に移る」を足した（saibanin-shikumi #1・kenko-minuki #5。ほかのゲームは各担当で）
- [x] 防ぐ: `routines/game-dev.md`「共通の形」に「ヒント」の行を足した（この PR）
- [x] 見つける: `scripts/drift-check.mjs` に `hint:cut-moves` を足し、まちがいの数で消す数が変わる `cutOf` が残るゲームを週次まとめに出す（この PR）
