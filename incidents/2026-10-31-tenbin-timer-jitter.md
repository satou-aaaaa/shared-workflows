# 天秤の書の本番形式模試で、上部の残り時間の表示がスマホで1秒ごとにカクカク動いた

- 種類: 表示
- 場所: tenbin（天秤の書）・行政書士の本番形式模試
- 気づいた人: satou さん
- 影響: 模試を解いている間、残り時間の枠が毎秒 83〜86px で伸び縮みし、390px 幅では枠が1行目と2行目を行き来して、問題文の位置も上下に2px動いた

## 起きたこと
- 2026-10-31 の UI/UX 改善（tenbin #40）で、模試の上部（問題番号・区分・残り時間・解答数）を画面の上に貼りつけた。
- 同じ日の夕方、satou さんから「模試の上の時間の部分がカクカクする（表示がずれる）」と報告があった。
- 計測すると、残り時間の値を変えるたびに枠の幅・位置と問題の位置が変わっていた（直す前の版で 320/360/390/1280px すべて）。

## 原因
- 残り時間は明朝体（Shippori Mincho B1）で表示していて、この書体の数字は字ごとに幅がちがう（`font-variant-numeric: tabular-nums` が効かない）。枠の幅を決めていなかったので、1秒ごとに幅が変わった。
- 上部は折り返す並べ方（flex-wrap）で、幅の差で折り返す位置が変わり、上部の高さと下の問題の位置まで動いた。上に貼りつけたことで、ずれが常に目に入るようになった。

## なぜ見つからなかったか
- UI点検（スキル law-app-ui-check）と tenbin の check.mjs は、ある一瞬のスクリーンショットと DOM を見るだけで、時間や操作で中身が変わる表示を「値を変えて測る」項目がなかった。
- 30日以内の「表示」の記録（2026-10-20 ボードの「⋯」メニュー、2026-10-22 ボードのボタンの増えすぎ）も、操作したあと・状態が変わったあとの表示を見ていなかった点が共通している。

## 対策
- [x] 直す: 残り時間の枠の幅を固定（時間切れの表示でも同じ幅）、解答数の欄も折り返さない（tenbin #42、Artifact v69）
- [x] 防ぐ: tenbin の `tools/check.mjs --browser` に、残り時間（role=timer）を14通りの値にしても枠の幅・位置と問題の位置が変わらないかを足した。直す前の版で NG、直した版で OK（tenbin #42）
- [x] 見つける: UI点検の手順（`bootstrap/skills/law-app-ui-check/SKILL.md`）に「時間や操作で変わる表示は、値を変えて幅・高さ・位置が動かないか測る」「PWA版（外側の指定なし）でも開く」を足した（この PR）
