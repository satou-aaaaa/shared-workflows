# 新作の学習ゲームに、写し元のリンク名と、取り違えた出典が残っていた

- 種類: 検査の見逃し
- 場所: 理科の学習ゲーム（energy-shurui・kagaku-henka・kitai-ate・kankaku-ate・kaseki-ate・shoka-koso・suiyoeki-ate・jikken-kigu）の `index.html`・`data.js`・`qa/run.mjs`
- 気づいた人: 新作を作るスレッド（実験器具あての土台を写したとき）と、CodeRabbit（suiyoeki-ate#1）
- 影響: 「このゲームについて」の「くわしく調べる所」で、別の県・機関へのリンクが「大阪府のホームページ」と出ていた（公開中の6作）。水溶液あての1問とまめ知識1つが、その記載の無い広島県の資料を出典にしていた（公開前）。答えの中身はまちがっていない。

## 起きたこと
- 新作は前のゲームを写して作る。リンク先 `CH` は直したが、リンク名は写し元のまま残った。
- 出典を1回に8つまとめて読ませたとき、岡山県の資料の文を広島県の資料のものとして記録し、そのまま出典にした。
- 答えの名前の検査を行全体の sed で直したとき、別の検査から石灰水も消えた（同じ夜、すでに直した）。

## 原因
- 写し元の言葉を見る QA（写し元の検査）は、ゲームの名前やキーだけを見ていて、リンク名は見ていなかった。
- 出典メモに、どの URL の文かを引用で残さずに要約していた。

## なぜ見つからなかったか
- リンク名とリンク先が合うかを見る検査が無かった。
- 出典の中身を確かめる検査は無く、CodeRabbit が資料を開いて初めて分かった。

## 対策
- [x] 防ぐ: 各ゲームの `qa/run.mjs` に、リンク先の持ち主の表 `CHNAME` と、リンク名がその名前で始まるかの検査を足した（直す前の画面で落ちることも確かめた）。新作は前のゲームから写すので、この検査も一緒に写る。
- [x] 防ぐ: 答えの名前の検査を `NAME_RE` にまとめ、答えの5つが全部入っているかを QA で見る。
- [x] 防ぐ: 出典は1回に1つの URL ずつ読み、出典メモには文をそのまま引用で残す（`routines/` ではなくプロジェクトのメモリ working-rules に書いた。2026-11-18）。
- [x] 直す: 公開中の6作は各リポジトリの PR #2、水溶液あて・実験器具あては PR #1 で直した。
