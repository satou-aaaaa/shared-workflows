# 別のスレッドに貼る文がボードのコメントに書かれ、届かなかった

- 種類: 連絡の行き違い
- 場所: claude.ai の TODO ボード（「TODO のカンバン化」スレッド）
- 気づいた人: 「TODO のカンバン化」スレッドの点検
- 影響: LAST TELL とカルカソンヌのスレッドに送るはずの許可の文が、ボードのコメントに書かれ、送り先に届かなかった。

## 起きたこと
- 2026-10-19 夜、ボードのカード「この文を〇〇スレッドに貼って送る」に対し、文がボードのコメント欄に書かれた。
- コメントはボードの担当にしか届かないので、送り先のスレッドは許可を受け取れなかった。

## 原因
- カードには「別のスレッドに貼る」と書いてあるだけで、ボードの中にその手段が無かった。目の前にあるコメント欄に書くのが自然だった。
- 安全チェックの都合で、その文は satou さん本人がそのスレッドに書く必要がある。代わりに届ける道が無い。

## なぜ見つからなかったか
- カードを作るとき、「satou さんがこのカードからどう動くか」を最後までたどっていなかった。

## 対策
- [x] 直す: LAST TELL とカルカソンヌのカードを作り直した
- [x] 防ぐ: 「別のスレッドに貼る文」のカードに「文をコピーして開く」ボタンを付けた。押すと文がコピーされ、送り先が開く（ボード18版）
- [x] 弱める: コメント欄に「ここに書いても他のスレッドには届きません」の注意を出した（ボード19版）
