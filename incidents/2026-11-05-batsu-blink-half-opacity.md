# ×はどこだの見やすさの検査が、点滅の途中の半分の濃さに当たると落ちた

- 種類: 検査の見逃し
- 場所: batsu-doko の感染の画面（`#virus .warn` の点滅）と qa/a11y.mjs のコントラストの検査
- 気づいた人: 引き継ぎコード版5を配っていたスレッド（batsu-doko #22 の QA）
- 影響: 引き継ぎコードの PR の QA が1回落ち、マージが遅れた。遊ぶ人への影響は無い（点滅の途中の一瞬だけ字がうすくなる）。

## 起きたこと
- 2026-11-05、batsu-doko #22（引き継ぎコード版5、transfer.js と検査だけの変更）の QA が「⚠ SYSTEM ALERT のコントラスト 2.11（4.5 未満）」で落ちた。手元の QA と前の PR では通っていた。

## 原因
- 点滅が `animation:blink .5s steps(2) infinite`（`@keyframes blink{50%{opacity:0}}`）で、`steps(2)` は 1→0 の間を2段に分けるので、濃さ 0.5 の時ができる。検査がその時に測ると、うすい字としてコントラスト不足になる。
- 濃さ 0 の時は検査が測らず、1 の時は足りるので、測る時刻しだいで通ったり落ちたりした。

## なぜ見つからなかったか
- 検査は1回だけ測る。点滅の途中の濃さを見る決まりも検査も無かった。

## 対策
- [x] 直す: batsu-doko の点滅を `blink 1s step-end infinite` にした（見える・消えるの2つだけ。1秒に1回で、光る回数の決まり A8 の内）（batsu-doko #22）
- [x] 見つける: batsu-doko の qa/run.mjs に「点滅（blink）は step-end で、半分の濃さの時が無い」を足した（batsu-doko #22）
- [x] 防ぐ: routines/game-dev.md の A8 に「点滅は step-end で見える・消えるの2つだけ」を足した（この PR）。ほかのゲームに `steps(2)` の点滅は無いのを確かめた
