# 地に模様のあるゲームで、字のコントラストの検査がほとんど何も測っていなかった

- 種類: 検査の見逃し
- 場所: shared-workflows template/qa/a11y.mjs（写したゲーム全部）
- 気づいた人: Claude（まんなか漢字に写す作業で）
- 影響: body に和紙・布目などの模様を敷いたゲーム。まんなか漢字の金の字（2.68:1）、株ニュースの上げ・下げの字（4.3:1）・実績の小さい字（4.04:1）が、検査を通ったまま残っていた

## 起きたこと
- コントラストの検査は、字のうしろを親へたどって色を重ねる。途中に絵（background-image）があると「測れない」として、その字を数えなかった。
- body に模様を敷くと、画面のほとんどの字が「測れない」になり、1か所でも測れれば検査は ✅ になっていた。

## 原因
- 絵の上の字は色が決まらないので飛ばす、という作りを、ページ全体の薄い模様にも当てはめていた。飛ばした数も出していなかった。

## なぜ見つからなかったか
- 検査の結果に「何か所を測ったか」しか出ず、「何か所を飛ばしたか」が分からなかった。

## 対策
- [x] 直す: html・body の模様は、下に敷いた地の色（background-color が不透明のとき）で測る（template/qa/a11y.mjs）。株ニュースの足りない色を濃くした
- [x] 見つける: 測れなかった字の数を検査の結果に出し、自分の目で見るよう書く（`template/qa/a11y.mjs` の「3. コントラスト」）
- [x] 防ぐ: `routines/game-dev.md` の A3 に「地に絵がある所は地の色だけの画面でも自分で測る」を足した。`scripts/drift-check.mjs` がひな形と違う写しを出すので、全ゲームに写し直す
