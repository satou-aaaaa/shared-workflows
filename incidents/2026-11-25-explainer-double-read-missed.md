# 読みの検査が「ききゃく（ききゃく）」の二重読みを見逃した

- 種類: 検査の見逃し
- 場所: 小江戸ゲーム部の解説動画（yomi.py・gate_explainer.py）
- 気づいた人: ニュース解説のスレッド
- 影響: N1 の台本で3語（棄却・肖像・顧客吸引力）を2回読む音声ができかけた。公開前に気づき、公開された動画への影響はない

## 起きたこと
- 同じ日の [2026-11-25-explainer-voice-misreading.md](2026-11-25-explainer-voice-misreading.md) の対策で、ふりがな「漢字（かな）」を かなだけ読む処理と検査を入れた。
- N1 は台本ごとの読みの置きかえ表で「棄却」を先に「ききゃく」にしていたため、読ませる文が「ききゃく（ききゃく）」になった。
- yomi.py check はこれを OK にした。

## 原因
- ふりがなの処理と検査が「漢字（かな）」の形だけを見ていた。漢字が先に別の手順でかなに置きかわると、形が「かな（かな）」になり、どちらにも当たらなかった。
- 「同じ読みが続けて2回」という結果そのものを見る検査がなかった（入力の形を見る検査だけだった）。

## なぜ見つからなかったか
- 前の対策の selftest は「漢字（かな）」の例だけで、ほかの手順と重なった例を入れていなかった。

## 対策
- [x] 直す: N1 の台本はニュース解説のスレッドで直した
- [x] 防ぐ: `yomi.py` の to_read で、読ませる文に残った「（かな）」は形によらず消す（同じ語を1回だけ読む）
- [x] 見つける: `yomi.py` に dup_problems・pron_dup を足した。読ませる文に「（かな）」が残っている、またはふりがな・辞書の語の読みが続けて2回出たら NG。selftest に「ききゃく（ききゃく）」「棄却ききゃく」の例を足し、直す前 NG・直した後 OK を確かめた
- [x] 見つける: `gate_explainer.py` の H でも、実際に読ませた文を dup_problems で見る（pyopenjtalk の無い PC でも動く）。古い作り方の音声で NG、作り直しで OK を確かめた
- [ ] 防ぐ: PC の共通フォルダ `_common` に新しい yomi.py と gate_explainer.py を写す（担当: 転送のスレッド、期限: 2026-11-26）
