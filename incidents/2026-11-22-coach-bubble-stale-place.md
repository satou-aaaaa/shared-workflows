# はじめての案内の吹き出しが古い場所に残り、押す所を隠すことがあった（震度よみ）

- 種類: 表示
- 場所: `template/core/core.js` の `Core.coach`（版2まで）
- 気づいた人: Claude（Template sync の PR shindo-yomi #7 の QA が GitHub の上でだけ落ちた。main の QA も同じく落ちた）
- 影響: 練習の1問で、吹き出しが次に押すボタンの上に残ることがあった（遊ぶ人は「案内を閉じる」かページを動かせば進める）。QA は「game-core の検査が最後まで動く（locator.click: Timeout 30000ms exceeded.）」で止まり、Template sync の PR が1本マージされなかった。

## 起きたこと
- 正解のあとの吹き出しを、ページが動く前の場所に出したまま、場所を測り直さないことがあった。手元では15回回して一度も起きず、GitHub の機械では版2で3回続けて落ちた。

## 原因
- 吹き出しの場所を測り直すのは、DOM の足し引き・画面の大きさの変化・スクロール・出した直後の3回（0.12・0.35・0.8 秒）だけだった。字の読み込みや開く動きのような見た目だけの変化では知らせが来ず、遅い機械では3回の測り直しのあとにページが動いた。

## なぜ見つからなかったか
- QA は吹き出しが重ならないかを最初の1つでしか見ていなかった。2つ目からは押せるかどうかだけを見て、止まったときも「Timeout」の1行しか残らず、どこで止まったか分からなかった。

## 対策
- [x] 直す: 吹き出しを出しているあいだ 0.4 秒ごとに場所を測り直す（core 版3）。GitHub の上で版3を9回回して8回通った（版2は3回とも落ちた）。
- [x] 防ぐ: `template/qa/core-check.mjs` に「練習の1問を進めるあいだ、吹き出しが押す所を2秒より長く隠さない」を足した（全部の吹き出しで見る）。
- [x] 見つける: `template/qa/core-check.mjs` が止まったときは、どの段（何番目の吹き出し）で何を待っていたかを1行目に出す。残りの1回の失敗もこれで次に分かる。
