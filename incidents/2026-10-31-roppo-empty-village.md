# うそつき六法の見本で、村人が0人の村ができて止まることがあった

- 種類: 動作
- 場所: usotsuki-roppo（うそつき六法）の見本（Artifact 版）
- 気づいた人: 新しいリポジトリに入れる前に足した検査（QA）
- 影響: 遊んでいる途中、ある段の「間違った話」を使い切ると、次の村に村人が1人も出ず、エラーで先へ進めなくなった（見本を公開していた約1時間のあいだ）

## 起きたこと
- 2026-10-31、satou さんの感想に合わせて、話に易・中・難を付け、村ごとに4人を選ぶ形にした見本を公開した。
- リポジトリに入れる前に QA（`qa/run.mjs`）を作って回すと、5回に1回ほど「Cannot read properties of undefined」で落ちた。
- 調べると、村を作る関数が、正しい話と間違った話の両方が入る組を50回探して見つからないと、空の村を返していた。

## 原因
- 易しい段は12話のうち間違った話が3つしかなく、出た話を除いて選ぶため、3村目あたりで間違った話が残らなくなる。そのとき「両方入る組」が作れず、代わりの選び方が無かった。

## なぜ見つからなかったか
- 公開前の確かめは「5つの村を1回通して遊ぶ」だけで、乱数で組む部分を何度も作って見る検査が無かった。1回の通しでは、たまたま使い切らない並びになることが多い。

## 対策
- [x] 直す: まだ出ていない話→同じ段の全部の順で組を探し、それでも無ければ偏りを許して必ず4人そろえる（usotsuki-roppo #1、Artifact v7）
- [x] 防ぐ: 段ごとに村を300回ずつ作り、毎回4人そろうか・正しい話と間違った話が両方入るかを見る検査を QA に足した。直す前の版で落ちることを確かめた（usotsuki-roppo #1 の `qa/run.mjs`）
- [x] 防ぐ: usotsuki-roppo の `AGENTS.md` に「乱数で組む部分は何百回も作って毎回の結果を確かめる」を足した（usotsuki-roppo #1）
