# やりくり商店街の説明書：手元では紙に入ったのに CI ではみ出した

- 種類: 公開・CI
- 場所: satou-aaaaa/yarikuri-shotengai の `print.html`・`print-lite.html` の1枚目（説明書）、`qa/run.mjs`「どの紙からもはみ出さない」
- 気づいた人: PR #6 の QA（run 43083373031）
- 影響: PR #6 の QA が赤。公開中のページは変わっていない（マージ前に止まった）。

## 起きたこと
- 客メーター・陣取り・コミのきまりを説明書に足した。手元の QA は全部通ったが、CI では2つの説明書がどちらも「はみ出す」になった。

## 原因
- 説明書の空きが、手元で 0.8mm（印刷）・5mm（少ない版）しか残っていなかった。字の形（読みこめた字・代わりの字）は手元と CI でちがい、CI では行が少し多くなって数mm足りなくなった。
- 2段組みが左右に決まった中身を入れる形（grid）で、左の段だけが長く、右の段は 20〜45mm 空いていた。

## なぜ見つからなかったか
- 検査は「はみ出さない（0mm 以上）」だけを見ていて、どれだけ余っているかを見ていなかった。手元の字でぎりぎり入ると通ってしまう。

## 対策
- [x] 直す: 説明書の2段を、中身が自動で左右にそろう段組み（CSS の columns）にし、文を少し短くした。空きは手元で 8〜23mm（代わりの字でも）。
- [x] 防ぐ: QA（`qa/run.mjs` の `slackMm`）に「説明書の下に 5mm 以上の空きがある」を足した（両方の版、yarikuri-shotengai #6）。字の形が少しちがう端末でも、はみ出す前に赤になる。
- [x] 防ぐ: 印刷用の紙をもつほかのゲームも、空きを見るように `routines/game-dev.md` の手順6に1行足した。
