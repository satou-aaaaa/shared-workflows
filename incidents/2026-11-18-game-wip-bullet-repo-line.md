# 別スレッドが箇条書きで書いた「- repo:」を読めず、作りかけの題材を候補と数えた

- 種類: 動作
- 場所: shared-workflows `scripts/game-wip.mjs`（毎日の新作の回 game-factory.md）
- 気づいた人: 毎日の新作の回（2026-11-18）
- 影響: 「題材:」Issue #380 信号よみ・#389 送りがなどっちが、別スレッドがもう作って公開済み（shingo-yomi・okurigana-dotchi）なのに候補の先頭に出て、毎日の回が「候補 #380 を始める」と出した。始める前に気づいたので、二重に作ったゲームは無い。

## 起きたこと
- 2026-11-17 夜、並列のスレッドが #380・#389 の本文に `- repo: shingo-yomi`・`- thread: …` と箇条書きで書いた。
- 2026-11-18 の毎日の回で game-wip が2つを候補と読み、「空きあり：候補 #380 を始める」と出した。リポジトリを探すと、どちらも Pages で公開済みだった。
- 同じ日、#509 代理のきまりも本文に repo: の行が無いまま、別スレッドが dairi-kimari の PR #1 を出していた。

## 原因
- `repoOf`・`branchOf`・`threadOf` が行の頭の `repo:` だけを読み、箇条書きの `- repo:` や `` `名前` `` で囲んだ形を読まなかった。
- 手順書は「本文に `repo:` の行を足す」とだけ書き、行の形（頭に何も付けない）までは書いていなかった。人や AI は本文を箇条書きで書きやすい。

## なぜ見つからなかったか
- `check-game-wip.mjs` の答えは、どれも行の頭が `repo:` のものだけで、箇条書きの形を試していなかった。
