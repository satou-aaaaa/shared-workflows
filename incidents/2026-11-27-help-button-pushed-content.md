# 全ゲームへ配る「？ 遊び方」などの写しで、8本のゲームの QA が落ちて配布が止まった

- 種類: 公開・CI
- 場所: `template/core/core.js`（game-core 版8）・`scripts/sync-template.mjs`（Template sync）
- 気づいた人: Claude（SNS 共有のスレッドが、Template sync の配布で QA が落ちたゲームを見つけた）
- 影響: 部首たしざん・かさね染め・星座つなぎ・切符10・しりとり最短・都道府県リレー・くすりよみ・おつかいメモの8本で、ひな形の写しの PR が QA で止まった。main には入っておらず、遊ぶ人には届いていない。

## 起きたこと
- 2026-11-27、game-core 版5〜8 で、ページの右上に「？ 遊び方」を置き、重ならないようにページの上をいつも 52px 空けた。
- 1画面目に入れる決まりのあるゲーム（部首たしざん・かさね染め・星座つなぎ・切符10）で、ボタンが画面の外へ押し出され、QA が落ちた。
- しりとり最短は、「戻る」（history.back）のあとブラウザが前のスクロール位置を当て直し、ホームが途中から出た。
- 都道府県リレーは、QA が手写しの buzz の行を正規表現で見ていたのに、写しがその行を `Core.buzz` に替えた。
- くすりよみ・おつかいメモは、文字の大きさを見やすさの設定へ移す写し（a11y v9）で、ゲームの QA の前提が変わった（担当は文字の大きさのスレッド）。

## 原因
- 「？」の置き場所を、どのゲームでも同じ 52px 空ければ足りるとして、ゲームごとの1画面目の詰まり方を見ていなかった。
- Core.screens.route が history.back を使うのに、スクロール位置の当て直し（history.scrollRestoration）を止めていなかった。
- 手写しの行を Core.* に替える写しが、ゲームの QA がその行を文字のまま見ていることを確かめていなかった。

## なぜ見つからなかったか
- 写す前に試したゲームは、1画面目に余裕のあるものだけだった。core の検査（check-core・check-core-qa）は「？」が重ならないかだけを見て、ほかのボタンを押し出すかは見ていなかった。

## 対策
- [x] 直す: 「？」を 44px の丸にし、ホームで重なるときだけ要るぶん空ける。空けると1画面目のボタンが外へ出るホームと、ほかの画面では、重なるあいだ隠す（game-core 版9。この PR）
- [x] 直す: Core.screens.route で `history.scrollRestoration = "manual"` にする（`template/core/core.js`・`template/screens/screens.js`。この PR）
- [x] 防ぐ: `keepQaLines`（`scripts/sync-template.mjs`）が、ゲームの QA が `/…/.test(html)` で見ている手写しの行を Core.* に替えない。check-core が確かめる（この PR）
- [x] 防ぐ: `scripts/check-core-qa.mjs`（Selftest）が、右上に押せる所があり1画面目の下ぎりぎりにボタンがあるホームで、「？」がボタンを外へ押し出さず重ならないかを見る（版8 では落ちる。この PR）
- [x] 見つける: `template/qa/core-check.mjs` が、隠れた「？」のときもフッターに遊び方の入口があるかを見る（この PR）
