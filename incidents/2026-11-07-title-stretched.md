# ホームの題が縦に伸び、iPad の縦などで題の下に大きなすき間が出た

- 種類: 表示
- 場所: satou-aaaaa の公開ゲーム8本（条文討伐・きまり探し・町の道順・おつかいメモ・お金のきほん・グラフみぬき・健康情報みぬき・歴史ならべ）
- 気づいた人: 世界の時刻のスレッド（820×1180 の画面写し）
- 影響: 縦に長い画面でホームを開くと、題の文字の下に 277〜450px の空白ができ、ボタンが画面の下へ押し出された。幅390pxでも条文討伐は題が128pxあった

## 起きたこと
- 2026-11-07、地形あて（chikei-ate #2）で、ホームの題が縦に伸びるのを見つけて直した。同じ書き方のゲームを調べると8本で起きていた。

## 原因
- 上の帯の見出しのために `h1{…;flex:1}` と書いていた。ホームの題も `h1`（`class="title"`）なので `flex:1` を受け継ぎ、ホームを縦に並べる flex の中で、余った高さを全部取って伸びた。
- 新しいゲームは前のゲームの index.html を写して作るので、同じ書き方が広がった。

## なぜ見つからなかったか
- QA と画面写しは、スマホの幅390×844 とパソコンの横長だけで見ていた。縦に長い画面（iPad の縦 820×1180）では、余った高さが大きいので初めて目立つ。
- 題の高さを見る検査が無かった。

## 対策
- [x] 直す: 8本の `.title` に `flex:none` を足した（各ゲームの PR。2026-11-07）。直したあと 820×1180・390×844・1280×800 で題の高さは文字1〜2行ぶん（43〜71px）
- [ ] 直す: 同じ書き方の新作18本（悪質商法・防災・地形あて・地図記号ほか。2026-11-07 に公開中の57本を調べて見つけた）にも `flex:none` と QA の検査を入れる（担当: ゲームの UI/UX 改善のスレッド 期限: 2026-11-08）
- [x] 見つける: 8本の `qa/run.mjs` に「ホームの題は縦長の画面でも縦に伸びない（820×1180・390×844・1280×800）」を足した（題の高さが、伸びない形より4pxを超えて高ければ失敗）。`scripts/drift-check.mjs` の `title:flex` が、`h1{flex:1}` を受け継いだまま `.title` に `flex:none` が無いゲームを週1の点検で出す
- [x] 防ぐ: `routines/game-dev.md` の「共通の形」に「ホームの題」の行を足した
