# ボードの「少なめ／多め」ボタンが、押しても選んだ側の色にならない

- 種類: 操作の反応
- 場所: claude.ai の TODO ボード（「TODO のカンバン化」スレッド）
- 気づいた人: satou さん
- 影響: カードの表示は切り替わるのに、ボタンの見た目はそのまま。どちらが選ばれているか分からない。

## 起きたこと
- 2026-10-19 夜、ボードの23版で「すっきり／くわしく」を「少なめ／多め」に名前を変えた。
- 同じ夜、satou さんから「押してもボタンの色が変わらない」と報告があった。

## 原因
- 押したときの処理が、カードの表示だけを切り替え、ボタンの「選ばれている」印（クラスと aria-pressed）を更新していなかった。
- 切り替えボタンごとに印を付ける処理を書いていて、共通の作りになっていなかった。1つ書き忘れると、そのボタンだけ壊れる。

## なぜ見つからなかったか
- 公開前の確かめは「カードの表示が変わるか」だけを見ていて、ボタンの見た目は見ていなかった。
- ボードは claude.ai の Artifact で、リポジトリの QA（CI）が回らない。毎回同じ検査を回す仕組みが無かった。

## 対策
- [x] 直す: 「少なめ／多め」の選択の印を更新するようにした（2026-10-19 夜のボードの更新）
- [x] 見つける: ほかの切り替え（見かた・担当・プロジェクト・記録の期間・テーマ・壁紙・透け具合・明るさ）も自動で1つずつ押して確かめ、同じ問題が無いことを確かめた。「絞り込み」は条件を入れたら「絞り込み中（1）」と出るようにした
- [x] 見つける: ボードを公開する前に毎回、すべての切り替えボタンを押して選択の印（aria-pressed）と見た目が変わるかを確かめる検査を回す（共有フォルダ `board/check-toggles.mjs`、手順は `board/README.md`。直す前の版で2件を失敗として拾い、直した版で全部通ることを確かめた）
- [ ] 防ぐ: 同じ作りの local-kanban の `qa/run.mjs` に、切り替えボタンを押すと aria-pressed が変わる検査を足す（担当: local-kanban の受け入れ、期限: 2026-10-26）
