# 見やすさの設定が、別のタブで消えたり、壊れた値で開けなくなったりした

- 種類: 検査の見逃し
- 場所: satou-aaaaa/shared-workflows `template/a11y/a11y.html`・`template/qa/a11y.mjs`（全ゲームの写し）
- 気づいた人: CodeRabbit（usotsuki-roppo PR #19 のレビュー）
- 影響: 2つのタブで設定を変えると、あとで保存したタブが先の変更を消した。保存した値が `true` などオブジェクトでないと、「Aa」も設定の画面も作られなかった。声の一覧があとから届いても「声がありません」が消えなかった。

## 起きたこと
- うそつき六法の見やすさ対応の PR に、CodeRabbit が上の3つを指摘した。どれもひな形の写しなので、全ゲームで同じことが起きうる。

## 原因
- 設定を書くとき、読み込んだときの値をそのまま書いていた（読み直していなかった）。
- 読み込んだ値の形（オブジェクトか）を確かめていなかった。
- 声の一覧の `voiceschanged` を聞いていなかった。

## なぜ見つからなかったか
- 検査は1つのタブで「選ぶ→開き直す→残る」だけを見ていて、別のタブ・壊れた値を試していなかった。

## 対策
- [x] 直す: 書く前に読み直して合わせる・オブジェクトでなければ無かったことにする・`voiceschanged` で出し直す（`template/a11y/a11y.html` v5）。写しを全ゲームへ配る
- [x] 見つける: `template/qa/a11y.mjs` に「別のタブで変えた設定を消さない」「保存した値が壊れていても設定を開ける」を足した
- [x] 防ぐ: 記録を保存する所は「保存の前に読み直す」がゲームの記録の決まり（各ゲームの `AGENTS.md`）。見やすさの設定にも同じ検査を入れたので、ひな形を変えても検査が見る
