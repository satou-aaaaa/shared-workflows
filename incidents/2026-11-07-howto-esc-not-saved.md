# 遊び方を Esc で閉じると「見た」が残らず、ホームに戻るたびに遊び方が開いた

- 種類: 操作の反応
- 場所: satou-aaaaa の公開ゲーム21本（間取りパズル・都道府県リレーほか）と、お金のきほん
- 気づいた人: お金のきほんの CodeRabbit のレビュー
- 影響: 遊び方（dialog）を Esc・戻る操作で閉じた人には、開くたびに遊び方が出た。「わかった」を押した人には起きない

## 起きたこと
- 各ゲームは、はじめて開いたときに遊び方を出し、「わかった」で閉じると記録に `tut` を残して、次からは出さない。
- 2026-11-07、お金のきほんのレビューで、Esc で閉じると `tut` が残らないと分かった。同じ書き方が21本にあった。

## 原因
- `tut` を残す処理を「わかった」のボタン（`$("howto-ok").onclick`）の中にだけ書いていた。`<dialog>` は Esc でも閉じられるが、そのときボタンは押されない。
- 新しいゲームは前のゲームの index.html を写して作るので、同じ書き方が全部に広がった。

## なぜ見つからなかったか
- QA は「わかった」を押して閉じる道だけを試し、Esc で閉じる道を試していなかった。

## 対策
- [x] 直す: 21本とお金のきほんで、「わかった」を押したらすぐ `tut` を残し、dialog の `close` イベントでもまだなら残す（どの閉じ方でも残る。`close` だけにすると知らせが遅れて届き、押した直後に読み直すとまた出ることが、お金のきほんの CI で分かった）。QA に「Esc で閉じても開き直したとき出ない」「押してすぐ読み直しても出ない」を足した
- [x] 見つける: `scripts/drift-check.mjs` の `howto:close` が、`close` で残していないゲームと、「わかった」ですぐ残していないゲームを毎日の点検で出す
- [x] 防ぐ: `routines/game-dev.md` の「共通の形」に、押したらすぐ残し `close` でも残す・QA で Esc とすぐ読み直す道も試す、を書いた
