# 「リポジトリ作成は AI に任せる」と言ったのに、新作のたびに satou さんが作成リンクを押していた

- 種類: 連絡の行き違い
- 場所: 新作のスレッド（次のゲームを作って公開する・認知症予防につながるゲームを作る ほか）と routines/onboarding.md
- 気づいた人: satou さん（「以前も同じことを言っていると思います」）
- 影響: 2026-11-04〜05 の新作の多く（ことばならべ・otsukai-memo など）で、satou さんが作成リンクを開いて押した。同じ頼みを satou さんが2回した。

## 起きたこと
- 2026-11-04 satou さんが「リポジトリ作成・Pages 設定は AI におまかせ」と言い、メモリに残った。
- 11-05 新作のスレッドが Chrome で「Create repository」を押すと、自動の安全チェックに「公開の場を作る」として止められ、satou さんにリンクを渡す形に戻った。
- 同日 satou さんが「今後はリポジトリーの作成までお願いしたい」と再び頼んだ。このスレッドでも、コーディネーターの引用だけでは同じく止められた。

## 原因
- 安全チェックは「公開の場を作る」操作を、その会話（スレッド）に本人の言葉があるときだけ通す。メモリの記録・別スレッドの言葉・コーディネーターの引用は見ない。
- 手順書（onboarding.md）にリポジトリを作る手順そのものが無く、game-dev.md は「作れないときはリンクを渡す」とだけ書いていた。止められたときに、本人の一言をそのスレッドで頼む道が書かれていなかった。

## なぜ見つからなかったか
- 止められたスレッドはそれぞれリンクを渡して先へ進み、「なぜ止まるか」を調べて手順に戻す場所が無かった（メモリの new-games-round3 に一行あるだけ）。
