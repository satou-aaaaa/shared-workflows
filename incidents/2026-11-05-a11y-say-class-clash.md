# 見やすさの設定の「読み上げ」を入れると、画面全体が左へずれた

- 種類: 表示
- 場所: shared-workflows template/a11y/a11y.html（写しの kippu-10 に入っていた）
- 気づいた人: Claude（kabu-news に写す作業で）
- 影響: 見やすさの設定で「読み上げのボタンを出す」を入れた人。kippu-10 で 2026-11-05 の数分間。画面が縮んで右へ寄り、ボタンが押せなくなるゲームがあった

## 起きたこと
- 設定を入れると html に `a11y-<名前>` の印（class）が付く。読み上げは `a11y-say`。
- 読み上げボタンの見た目も `.a11y-say{position:fixed;…}` と同じ名前で書いていたため、html そのものが fixed の箱になり、画面がずれた。

## 原因
- 設定の印（html の class）と、部品（ボタン）の class に同じ名前の作り方（`a11y-` + 名前）を使い、ぶつかる名前を作っていた。

## なぜ見つからなかったか
- 検査（qa/a11y.mjs）は「設定を全部入れた」画面で字のコントラストは見ていたが、画面の置き場所・横のはみ出しは見ていなかった。kippu-10 は幅が狭く、押す検査にも当たらなかった。

## 対策
- [x] 直す: ボタンの class を `a11y-saybtn` に変え、設定の印とぶつからないようにした（`template/a11y/a11y.html` 版 v2）。全部のゲームに写し直す
- [x] 見つける: `template/qa/a11y.mjs` が、ふつう・設定を全部入れた画面で、html が static のまま・横にはみ出さない・本体が左へずれないことを見る
- [x] 防ぐ: `template/a11y/a11y.html` の先頭のコメントに、設定の印は `a11y-<設定の名前>`、部品の class はそれと重ならない名前にすることを書いた
