# ボードのカードの「⋯」メニューが、下のカードや隣の列に隠れて読めなかった

- 種類: 表示
- 場所: claude.ai の TODO ボード（「TODO のカンバン化」スレッド）
- 気づいた人: satou さん（「『・・・』を押しても、表示が被ってしまい見えなくなっています」）
- 影響: 壁紙を使っているとき、どの列でもメニューの項目（「急いで」「済みにする」「詳細・コメント」など）が下のカードに隠れて押せなかった。

## 起きたこと
- 2026-10-20、satou さんがカードの「⋯」を押すと表示が重なって見えないと知らせた。
- 公開前の検査（check-toggles.mjs）に「メニューの各項目の真ん中が、ほかの要素に隠れていないか」を足して回すと、壁紙ありで5列すべて ❌、壁紙なしは ✓ と再現した。

## 原因
- 壁紙ありのとき、カードと列に半透明のぼかし（backdrop-filter）を付けている。backdrop-filter を付けた要素は、それぞれ別の重なりの層（stacking context）になる。
- そのため、メニューの z-index はカードの中でしか効かず、あとに描かれる下のカードや隣の列がメニューの上に描かれた。

## なぜ見つからなかったか
- 公開前の検査は切り替えボタンの印だけを見ていて、メニューのような重なって出る部品が見えるかは見ていなかった。
- 壁紙は v20 で後から足したため、壁紙ありでの重なりを確かめる観点が無かった。

## 対策
- [x] 直す: メニューを開いている間は、そのカードと列を一番手前（z-index 30）に出す。画面の下で切れるときは上向きに開く（ボード v31）
- [x] 見つける: 公開前に毎回回す check-toggles.mjs に、壁紙なし・ありの両方で各列の先頭カードの「⋯」を開き、全項目が隠れていないかを確かめる検査を足した（直す前の版で ❌ 5件、直した版で ✓ を確認。スマホ幅でも ✓）
- [x] 防ぐ: 重なって出る部品（メニュー・ポップアップ）は、開いている間だけ親を手前に出す作りにそろえた。新しく足すときも同じ検査が拾う
