# コツ集の「言い切りが合わない」自動の知らせが3日直されず、Issue が増えたように見えた

- 種類: 見回りの見落とし
- 場所: satou-aaaaa/carcassonne-research の `ai-content.yml`・`human-games.yml`、ルーティン「研究を毎日1件ずつ進める」
- 気づいた人: satou さん（「issueも増えているようです」）
- 影響: コツ集（ai_tips.html）が3日間、最新AIでなく前の版のままだった。開いた Issue は3件（直しが要るもの1件、人の投稿待ち1件、採用の知らせ1件）。11月の自動 Issue は28件で、ほかは自動で閉じていた。

## 起きたこと
- 11/11、最新AIの集計で手持ちミープルの言い切り（「序盤の終わりに1〜2個」「中盤以降はほぼ使い切る」）が成り立たず、`data/tips_blocked.json` と Issue #173 ができた。

- X 投稿の下書き Issue（#200）は人の投稿を待つ形で、区切りごとに増える作りだった。

## 原因
- 「直しが要る自動の知らせ」を拾う担当が決まっていなかった。週1の放置点検は14日たってからしか気づかない。
- ミープル温存（PR #169）でAIの手持ちが多くなり、幅の狭い言い切りが外れた。
- X の下書きは、新しい区切りの下書きができても前の下書きを閉じなかった。

## なぜ見つからなかったか
- 毎日の研究の回（research-loop.md）は BACKLOG だけを見て、Issue を見なかった。放置点検（stale-check.yml）は14日の幅なので、3日では出ない。
