# 見やすさの設定 v10 のコメントが、写した先のゲームの QA にかかって配布が止まった

- 種類: 公開・CI
- 場所: `template/a11y/a11y.html`（181行目のコメント）・各ゲームの `qa/run.mjs`（「一行の式の途中に // のコメントを置いていない」）
- 気づいた人: 共有（Core.share）の配布の見張り（Template sync の merge が 50 本を「ぶつかり・待ち（blocked）」で止めていた）
- 影響: 2026-11-27 03:30〜 UTC、ひな形を写す PR のうち約 45 本の QA が ❌ のまま、SNS 共有・成績・ダークモードなどの共通部品がそのゲームに届かなかった。遊ぶ人への害は無い（main は前のまま）。

## 起きたこと
- v10（#642）で足した `let changed = new Map(); // 要素 → 変える前の { prop: [値, 優先] }` の行が `}` で終わっていた。
- 古いひな形からできたゲームの QA は、`; // …}` で終わる行を「一行の式の途中にコメントを置いて、行の残り（}）を消している」と見て落とす。コメントの中の `}` も同じに見える。

## 原因
- ひな形の写す部品が、写した先のゲームの QA の文の決まりにかかるかを、shared-workflows の検査で見ていなかった。

## なぜ見つからなかったか
- その検査は約 45 本の古いゲームの qa/run.mjs にだけある。#642 の確かめは震度よみなど検査の無いゲームで行っていた。
- Template sync の merge は QA の ❌ を「blocked」としか書かず、理由が QA の失敗だと分かりにくかった。

## 対策
- [x] 直す: a11y.html のコメントを `}` で終わらない形にした（この PR）。
- [x] 防ぐ: `scripts/check-core.mjs`（Lint）が、template/ の写す部品に `; // …}` で終わる行があると落とす（この PR。わざと戻して落ちるのを確かめた）。
- [x] 見つける: Template sync の merge が、blocked の PR は先に検査を見て「検査が落ちた（qa / qa）」と書く（この PR）。
