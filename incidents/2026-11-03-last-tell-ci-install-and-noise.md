# last-tell の QA が2週間で33回失敗し、うち約13回が検査の揺れだった

- 種類: 公開・CI
- 場所: last-tell（.github/workflows/qa.yml）
- 気づいた人: satou さん
- 影響: 10/21〜11/3 に QA が33回失敗（成功742回）。揺れは約13回で、残りは本物の崩れを見つけたもの

## 起きたこと
- 10/21〜11/3 の QA の失敗33回を分けると、約20回は本物の崩れを見つけたもの、約13回はゲームと関係のない揺れだった。
- 揺れの例: 入れる段階で Playwright のブラウザの取得が、配り元の一時的な証明書エラーで落ちた（run 39683777941）。Lighthouse の点が1回の測定のぶれで基準を割った。
- 「合否」のステップは理由を出さずに落ちるので、ログを見ても揺れか本物かが分からなかった。

## 原因
- 入れる段階で Playwright のブラウザの取得が配り元の一時的な証明書エラーで落ちても、やり直しが無かった（run 39683777941）。
- Lighthouse は1回だけ測っていた。
- 「合否」のステップは理由を出さずに exit していた。

## なぜ見つからなかったか
- 揺れと本物の失敗を分けて数える仕組みが無く、「合否」のログにも理由が無かった。

## 対策
- [x] 直す: npm ci・playwright install を `qa/tools/retry.sh` でやり直す（last-tell #162）
- [x] 防ぐ: Lighthouse は3回測った真ん中の値で見る。ワークフローの入れる行が retry.sh を通っているかを単体テスト ci_flake が見る（last-tell #162）
- [x] 見つける: 「合否」のログに ❌ の一覧を出す（last-tell #162）
