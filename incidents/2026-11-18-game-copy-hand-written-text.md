# 新作を前のゲームから写したとき、遊び方・説明・まちがいの案内が写し元（行政の期限）の文のまま残った

- 種類: 検査の見逃し
- 場所: zeimu-kigen・kuruma-kigen・kazoku-kigen（新作を作るスレッド）
- 気づいた人: CodeRabbit（zeimu-kigen#1 のレビュー）
- 影響: 公開前の3本で、検索に出る説明文・遊び方・2段目をまちがえたときの案内が「審査請求・取消訴訟・情報公開」のままで、このゲームに無いきまりの名前を案内していた。公開中のゲームには出ていない（3本とも PR のうちに直した）。

## 起きたこと
- 行政の期限（gyosei-kigen）を写して税の期限を作り、それを写して車と免許の期限、家族と相続の期限を作った。
- 写すときの置き換えの手順に、`<meta name="description">`・遊び方の「その期限（…）」「どのきまりか（…）」・ホームの1行目・2段目のまちがいの案内（「✕ ちがいます。…」）が入っていなかった。

## 原因
- この5か所はゲームごとに手で書く文なのに、置き換える場所の一覧が無く、前のゲームで直した所だけを写していた。
- QA の「写し元の言葉が残っていない」検査の言葉の一覧に、すぐ前の写し元（行政の期限）の言葉を足し忘れた。

## なぜ見つからなかったか
- QA は2段目の3つの名前を data.js の側でしか見ておらず、画面の文がその名前で書いてあるかを見ていなかった。

## 対策
- [x] 直す: 3本の5か所を、それぞれのゲームのきまりの名前と期限の幅で書き直した（zeimu-kigen#1・kuruma-kigen#1・kazoku-kigen#1）
- [x] 防ぐ: 3本の `qa/run.mjs` に「遊び方・説明・まちがいの案内が、このゲームのきまりの名前（`G.GROUPS`）と期限の幅（`G.LEVELS` の最初と最後）で書いてある」検査を足し、写し元の言葉の一覧にすぐ前の写し元の言葉も足した（zeimu-kigen#1・kuruma-kigen#1・kazoku-kigen#1）
- [x] 防ぐ: `routines/game-dev-detail.md` A 手順5 に、写したときに必ず書き直す手書きの5か所と、すぐ前の写し元の言葉を登録することを書いた（この PR）
