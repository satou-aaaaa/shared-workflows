# 見やすさの「Aa」ボタンが、ホームの記録の上に重なって出ていた

- 種類: 表示
- 場所: `template/a11y/a11y.html`（見やすさの設定の共通部品。全ゲームの `index.html` の a11y:begin〜end）
- 気づいた人: Claude（2026-11-23 共通部品の点検で、全ゲームのホームをスマホ幅で測ったとき。satou さん「ホーム画面がごちゃごちゃになることがよくある」）
- 影響: 169本のゲームで、ホームの左下に「Aa」が出て「遊んだ日」の数に重なっていた。フッターにも「見やすさ」があり、同じ入口が二重だった。

## 起きたこと
- 共通部品は、作った時にページに入口（data-a11y-open）が無ければ左下に「Aa」を足す。多くのゲームはホームのフッターを JS で後から描くので、作った時には入口が無く、「Aa」が出たままになった。

## 原因
- 入口があるかを作った時の1回しか見ていなかった。ホームが後から描かれる形を考えていなかった。

## なぜ見つからなかったか
- qa/a11y.mjs は「入口がある」だけを見て、「二重に出ていない」「何かに重なっていない」を見ていなかった。
- 共通の画面の検査（ui-check）は172本で呼ばれていたが、設定ファイル（qa/ui-check.json）が無いと何も数えずに通っていた（別の記録 2026-11-23-common-parts-missing-in-apps.md で直す）。

## 対策
- [x] 直す: `template/a11y/a11y.html` v8。左下の「Aa」は、画面に見えている入口がほかに無いあいだだけ出す（MutationObserver で描き直しを見る）。出ているあいだは下をあけ、いちばん下の物が隠れたままにならないようにする（WCAG 2.4.11）。Template sync が全ゲームへ写す。
- [x] 見つける: `template/qa/a11y.mjs` に「ホームに見やすさの入口が二重に出ていない」を足した（全ゲームの QA が回す）。設定を開く検査は見えている入口（`[data-a11y-open]:visible`）を押す。
