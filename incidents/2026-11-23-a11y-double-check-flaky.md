# 「Aa が二重」の検査が、混んだ CI でだけ落ちた

- 種類: 公開・CI
- 場所: `template/qa/a11y.mjs`（ホームに見やすさの入口が二重に出ていない）
- 気づいた人: CI（otoku-dotchi #10・bousai-handan #20 の QA。2026-11-23 Template sync の PR）
- 影響: 写す PR が QA ❌ で止まった。手元では何度回しても通った。

## 起きたこと
- Template sync で多くのゲームの QA が同時に動いた時間に、「ホームに見やすさの入口が二重に出ていない」だけが落ちた。同じコミットでも、回し直すと通った。

## 原因
- 左下の「Aa」は、DOM が変わったあとの次の描画（requestAnimationFrame）で出し入れする（`template/a11y/a11y.html` の place）。検査は描画を待たずに数えたので、機械が混んでいると、フッターを描いた直後・「Aa」を隠す前の一瞬を数えていた。

## なぜ見つからなかったか
- 手元や空いた CI では描画がすぐ済み、待たなくても通った。

## 対策
- [x] 直す: 数える前に2回分の描画を待つ（`template/qa/a11y.mjs`）。この PR
- [x] 防ぐ: 画面の部品が描画のあとで変わる所を数えるときは、描画を待ってから数える、と `template/qa/a11y.mjs` のその所に理由を書いた。この PR
