# ボードの確認の答えが3〜4回ずつ重なって届いた

- 種類: 操作の反応
- 場所: claude.ai の TODO ボード（「TODO のカンバン化」スレッド）
- 気づいた人: 「TODO のカンバン化」スレッドの点検
- 影響: 同じ答えが3〜4回ずつ担当に届いた（sandbox の Issue の答えなど）。担当がどれを使うか迷う。

## 起きたこと
- 2026-10-19 夜、satou さんがボードの確認カードで答えを押した。
- 押しても画面が変わらなかったので、satou さんは何度か押し直し、同じ答えが3〜4回ずつ届いた。

## 原因
- 答えを送ったあと、画面に「届いた」が出ず、選択肢もそのまま押せた。押した結果が見えないので、押し直すのが自然だった。
- 二度押しを止める仕組みが無かった。

## なぜ見つからなかったか
- 公開前の確かめは「答えが届くか」だけで、「1回押したあとに画面がどうなるか」「2回押したら何が起きるか」を見ていなかった。

## 対策
- [x] 直す: 重なって届いた答えは最後の1つだけを使って担当に渡した
- [x] 防ぐ: 1回押せば「届けました」と出て、選択肢が閉じるようにした（ボード18版）
- [x] 見つける: 「ボードの切り替えボタンの選択の印が変わらない」件と同じ種類なので、そちらの「公開前にすべてのボタンを押して確かめる検査」でまとめて見る（[2026-10-19-board-toggle-state.md](2026-10-19-board-toggle-state.md)）
