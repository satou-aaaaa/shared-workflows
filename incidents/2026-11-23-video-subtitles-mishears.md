# 公開した長尺動画の字幕が、聞き間違いとゲームの読み上げだらけだった（LAST TELL 第2部）

- 種類: 検査の見逃し
- 場所: 小江戸ゲーム部の長尺動画（LAST TELL 第2部、11/23 公開）／スレッド「LAST TELL第2部の字幕間違いを直す」
- 気づいた人: satou さん（公開後）
- 影響: 公開済みの長尺 1 本（34 分）の画面の字幕と YouTube 字幕。自動検査で数えると誤り 55 件、ゲームの読み上げの字幕 135 区間。ショート 3 本の焼き込み字幕にも一部。

## 起きたこと
11/23 に録画を編集して公開した長尺で、「指定関係（師弟関係）」「首が治ってない（直ってない）」「でし（弟子）」「第10部（第1部）」など意味の通らない字幕が全体に残っていた。地名・名前も画面の表記と違った（潮見→汐見、都→ミヤコ）。ディーラーやキャラの読み上げまで実況者の発言として字幕になっていた。あわせて、セリフの区間がジャンプカットで切られて読めず、演出も少なかった。satou さんが公開後に気づき、作り直して上げ直した。

## 原因
- 文字起こしに、録画の「全部まざった音」のトラックを使っていた。声だけのトラックがあるのに、PC 用にその場で書いたスクリプトが 0 番を読んでいた。
- PC の作業用 Linux が小さい（2 コア）ので、いつもの道具（beam 5・用語ヒント）を使わず、軽い設定（beam 1・ヒントなし）で起こしていた。
- 直しは「見つけた誤りを置き換える一覧」だけで、全文を読んで直す工程と、その結果を置く場所が道具になかった。
- ジャンプカットは実況者の声と画面の動きで残す所を決めるので、黙ってセリフを聞いている区間が無音として切られた。

## なぜ見つからなかったか
- 書き出し後の検査（qc・字幕の時間・天の声の検査）は、時間・重なり・天の声しか見ず、字幕の言葉が正しいか・誰の声かを見る検査が無かった。
- 手順書の「字幕を全部読む」に、読んだ証拠を残す決まりが無く、飛ばしても公開まで進めた。

## 対策
- [x] 直す: 全文を画面の文字と照合して直し（165 か所）、ゲームの読み上げを外し、セリフの区間を残し、演出を足して書き出し直し、上げ直した（旧版は非公開）。`youtube/long_2026-11-23/proofread.json`
- [x] 防ぐ: 字幕の言葉の検査 `tools/subtext_check.py`。既知の聞き間違い・用語集の誤り・単語の途中の改行・名前の崩れを NG にする。旧字幕で NG 55 件、直した字幕で 0 件を確かめた。
- [x] 防ぐ: 声トラックの音量で、実況者の声が無い区間を字幕にしない `tools/long/voice_db.py`（設定 `subtitles.voice_db`）。ゲームのセリフ区間はジャンプカットで切らない（設定 `jumpcut.protect`、`tools/long/lt_cuts.py`）。
- [x] 防ぐ: 全文校正の結果を置く `subtitles.proofread`（`tools/long/lt_speech.py`）。変えたら字幕を作り直すよう `tools/long/long.py` が入力として見張る。
- [x] 防ぐ: PC 用の文字起こし `tools/transcribe_pc.py`。声のトラック・beam 5・用語ヒントを既定にし、`transcript_meta.json` に使ったトラックと設定を残す。
- [x] 見つける: 公開前の合格判定 `tools/gate.py`。声トラックでの文字起こし・全文校正・字幕の言葉の検査・天の声検査・演出の最低ライン・見直し記録がそろわないと NG（11/23 の設定で NG 8 件、そろえた設定で 0 件を確かめた）。
- [ ] 弱める: PC 本体（12 コア）で大きいモデルの文字起こしを動かす道を試す（担当: 小江戸ゲーム部の編集スレッド、期限: 2026-11-30）
