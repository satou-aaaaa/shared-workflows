# ひな形を配る PR の本文から、写すコマンドの文が消えた

- 種類: 手順の抜け
- 場所: ひな形（版12）を全ゲームへ配った作業（PR を作る手元のシェルスクリプト）
- 気づいた人: 配っていた担当（PR の本文を読み直したとき）
- 影響: 10本の PR の本文が「ひな形（版12、#264）を  で写した」となり、何で写したかが抜けた。ゲームの動きには影響なし。本文はあとで直した。

## 起きたこと
- 2026-11-07、版12を配る PR の本文を、引用しないヒアドキュメント（`<<EOB`）で書いた。
- 本文の中の `` `node scripts/sync-template.mjs ../<ゲーム>` `` が、シェルにコマンドとして走らされ（ゲームのフォルダでは見つからず失敗）、空の文字に置き換わった。
- 10本を出したあとで本文を読み直して気づき、スクリプトを直し、10本の本文を書き直した。

## 原因
- 引用しないヒアドキュメントは、`$変数` だけでなく `` `…` `` もコマンドとして走らせる。変数を入れたくて引用を外したため、Markdown のコードまで消えた。
- PR の本文を出す前に、消えた跡が無いかを見る仕組みが無かった。

## なぜ見つからなかったか
- スクリプトはエラーを出しても止まらない所（本文の組み立て）で失敗し、出力に紛れた。PR を作ったあとに本文を読む手順が無かった。

## 対策
- [x] 直す: 10本の PR の本文を書き直し、スクリプトの `` ` `` を逃がした（この PR の前に済み）
- [x] 防ぐ: `routines/pr.md` に「本文は `<<'EOB'` か `--body-file` で書き、出す前に検査を回す」を足した（この PR）
- [x] 見つける: `scripts/check-pr-body.mjs` を足した。本文の空のコード・2つ続きの空白で抜けた言葉・書き出されていない変数を見つけて落とす（この PR）
