# ずんだもん解説の音声が「手札」を「しゅさつ」と読み、ふりがなを二回読んでいた

- 種類: 検査の見逃し
- 場所: 小江戸ゲーム部の解説動画（make_voice.py・gate_explainer.py・md2json.py）
- 気づいた人: satou さん
- 影響: 解説動画22本の台本を点検し、14本・31行で読み間違いかふりがなの二重読み。予約済み4本のうち1本（11/28 公開予定の P1）に「手札」の読み間違いが2か所

## 起きたこと
- 2026-11-25、satou さんが「手札を、しゅさつ、など読み方が間違っている」「ふりがながあると二回読み上げる」と指摘。
- 点検すると、OpenJTalk（VOICEVOX の読みの元）の辞書が 手札=シュサツ、山札=ヤマサツ、一択=イチヨ、尊属殺=ソンゾクコロセ、短答式=タンコタエシキ などになっていた。
- 台本の「餅票（もちひょう）」のようなふりがなは、そのまま音声に渡り、漢字とかなの両方を読んでいた。

## 原因
- 音声に渡す文（read）を作る共通の読み辞書がなかった。各スレッドが台本ごとに置きかえ表を書き、ゲーム用語（手札など）は誰も足していなかった。
- make_voice.py は read をそのまま VOICEVOX に渡すだけで、ふりがなの処理がなかった。
- make_voice.py が作業フォルダごとにコピーされていて、直す場所が一つにまとまっていなかった。

## なぜ見つからなかったか
- gate_explainer.py は字幕と台本が一字一句同じかは見るが、音声が何と読んだかは見ていなかった。字幕は正しいので通っていた。
- 確認コマ（静止画）の見直しでは音が聞けない。

## 対策
- [x] 直す: 共通の読み辞書 `youtube/tools/yomi/yomi_dict.json` を作り、見つけた読み間違いを全部入れた。22本の台本がすべて正しい読みになることを確かめた（直す前 NG 58 件 → 直した後 0 件）
- [x] 防ぐ: 共通の `make_voice.py` を作り、読ませる文は必ず yomi.to_read（ふりがなは かなだけ1回・辞書を当てる）を通す。合成の前にエンジンの読み（audio_query の kana）でも辞書の語を確かめ、違えば止まる
- [x] 防ぐ: `yomi.py check` を作った。台本の全部の漢字の読みを出し、既知の読み違い・辞書どおりでない読み・ふりがなの二重読み・まだ誰も確かめていない読みを NG にする。make_voice.py はこの結果が OK で今の台本と一致しないと音声を作らない
- [x] 見つける: `gate_explainer.py` に H を足した。共通版で作った音声で、読みの点検が今の台本・辞書と一致しないと NG（直す前の音声 NG・直した後 OK を確かめた）
- [x] 防ぐ: `md2json.py`（台本 → narration.json）も yomi.to_read を通すようにした
- [x] 直す: 予約済みの P1 は 11/26 に直した音声で作り直して差し替えた（新しい ID は台帳。11/28 土曜の見直しで、X 告知の予定が差し替え後の ID を指しているのを確かめて閉じた）
