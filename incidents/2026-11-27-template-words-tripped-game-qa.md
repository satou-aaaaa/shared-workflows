# 写した共通部品の言葉や Ko-fi の置きかえを、古いゲームの QA が数えて配布が止まった

- 種類: 公開・CI
- 場所: `template/core/core.js`・`template/kiroku/kiroku.js`（コメントと記録の名前の行）・`scripts/sync-template.mjs`（Ko-fi の置きかえ）・各ゲームの `qa/run.mjs`
- 気づいた人: 共有（Core.share）の配布の見張り（#647 で直したあとも 40 本の「ひな形の共通部品を写す」PR の QA が ❌ のままだった）
- 影響: 2026-11-27、ひな形を写す PR のうち 40 本が QA で止まり、SNS 共有・成績・ダークモードなどの共通部品がそのゲームに届かなかった。遊ぶ人への害は無い（main は前のまま）。

## 起きたこと
- 古いゲームの QA には、index.html 全体やページの outerHTML を見る文の検査がある。
  - 「写し元の言葉が残っていない」（写して作ったもとのゲームの言葉。`pH`・`クモ`・`188`・`厚生労働省`・`しなくてよい` など）
  - 「言い方：必ず・絶対と言い切らない」「🎫・…すると開く・で開くを入れない」
  - 「Ko-fi は2か所だけ」（ko-fi.com の数）
  - 「記録の名前（KEY = "…-v1"）の行には gitleaks:allow がある」
- 共通部品を index.html に写すと、部品の中の言葉もその検査に入る。core のコメントの「必ず」「新しいタブで開く」「自分で開く」、kiroku の「必ず」と `KEY = "kiroku-v1"`、a11y の「ダークモード」（クモ）・`0.2817188376`（188）、core の `helpHas`（pH）などが当たった。
- Ko-fi の一文を `Core.kofi()`・`Core.KOFI` に置きかえた（#641）ため、ゲームの中の ko-fi.com が 2 から 1（core の中の1つ）になった。

## 原因
- ゲームの QA の「そのゲームが書いた言葉」を見る検査が、写した共通部品の中まで見ていた。共通部品の側は、ゲームの QA がどんな言葉を探すかを知らずに書いていた。

## なぜ見つからなかったか
- その検査は、写して作った古いゲーム 40 本ほどの qa/run.mjs にだけあり、言葉も 1 本ずつちがう。部品を足した PR の確かめは、検査の少ないゲームで行っていた。
- 前の止まり（#647）を直したあと、残りの理由を 1 本ずつ見ていなかった。

## 対策
- [x] 直す: core・kiroku のコメントを言いかえ、kiroku の記録の名前の行に gitleaks:allow を付けた（この PR）。
- [x] 防ぐ: sync-template の `ownQa` が、ゲームの QA の「写し元・言い方・Ko-fi・🎫・チケット」の検査（と a11y だけを外していた所）を `gameOwn(html)`（写しを外し、Core.kofi・Core.KOFI を写す前の形にもどしたもの）で見るように替える。check-core が ownQa・gameOwn を確かめる（この PR）。
- [x] 防ぐ: check-core（Lint）が、index.html に写す部品（core・kiroku・store・screens・a11y・parts）に「必ず・絶対・…で開く・🎫・チケット」などの言葉と、gitleaks:allow の無い記録の名前の行があると落とす（この PR。わざと「必ず」を足して落ちるのを確かめた）。
- [x] 見つける: 止まった 40 本を手元で写し直して QA を回し、残りの理由を確かめた（この PR の本文）。
