# satou さんがやり終えたカードが、ボードで「済み」にならなかった

- 種類: 見回りの見落とし
- 場所: claude.ai の TODO ボード（「TODO のカンバン化」スレッド）と、その見回りルーティン
- 気づいた人: satou さん
- 影響: satou さんがメールを送ったあとも、「連絡する」カードが「今やる」に残った。ほかの本人向けカード6枚も、やったかどうか分からないまま残っていた。

## 起きたこと
- 2026-10-20 の昼前、satou さんが自分でメールを送って、ある連絡を済ませた。
- その数分後、ボードのコメントを受けて、同じ連絡をするカードを「今やる」に足した。メールがもう送られていることは確かめなかった。
- 次の見回りでも、そのカードは済みにならなかった。
- その日の午後、satou さんから「チケットの内容を行っても、ステータスが更新されない」と報告があった。

## 原因
- 見回りが「済み」と判断する材料は、担当スレッドの状態・PR や Issue・ボードの答えとコメントだけだった。satou さん本人が外でしたこと（メールを送る、設定を変える、アプリを開く）の跡を見る手順が無かった。
- カードを足すときに、もう済んでいないかを確かめる手順が無かった。
- 証拠が無いときに satou さんへ聞く手段がなかった。残る手段はカードの「⋯」から手で済みにすることか、コメントを書くことだけだった。

## なぜ見つからなかったか
- 10/19 の「済みにならない」対策（[2026-10-19-board-done-cards-left.md](2026-10-19-board-done-cards-left.md)）は、Claude が担当するカードだけを見ていた。本人のカードが同じように残ることは考えていなかった。

## 対策
- [x] 直す: 送信済みメールを確かめ、連絡のカードを済みにした。ほかの本人向けカード6枚に「やりましたか？」の確認を付けた（2026-10-20）
- [x] 防ぐ: 見回りの手順10に (g) を足した。本人のカードは、送信済みメール・GitHub・カレンダー・ボードの記録・担当スレッドでの確かめから、毎回証拠を探して済みにする。カードを足す前にも同じ証拠を見て、済んでいるものは足さない（2026-10-20）
- [x] 防ぐ: 見回りの手順10に (h) も足した。証拠で分からない本人のカードには「やった／まだ」の確認を付ける。ボード v33 では「やった」を押すとその場で済みになり、Claude を待たない（2026-10-20）
- [x] 防ぐ: 同じ種類（見回りの見落とし）が30日で3件目のため、根本の仕組みも変えた。これまでは「済み」の見分け方を見回りが毎回推し量っていた。これからは、カードを作るときに `done_when`（済みの見分け方1行。例「相手への送信メールがある」「PR がマージ」）を必ず書き、見回りはそれをそのまま確かめる。書けないカードは最初から確認つきにする（2026-10-20）
- [x] 見つける: ボードの公開前検査（共有フォルダ `board/check-toggles.mjs`）に、確認カードで「やった」を押すと済みになるかの検査を足した。直す前の版で ❌、直した版で ✓ を確かめた（2026-10-20）
