# LAST TELL の提案の出し方

## 手順
1. 今のゲーム（/mnt/project-files/story/shisho.html）を読むだけにする。編集はしない（担当は「ストーリーモードの企画提案」スレッド）。
2. 今の作りと、それがどう見えるかの原因を短くまとめる。必要ならスクリーンショットも撮る。
3. 案を3〜5個出し、おすすめを1つ選ぶ。
   - 見た目は「かっこいい・クール」な方向にする。明るいポップなアニメ調は使わない。
   - 作り物っぽさより、実際のライブポーカーに近いものを選ぶ（例: きれいな塔より、ごちゃっと積まれたチップ）。
   - ボタンなどの操作はむやみに増やさない。
   - 第1〜3章の難しさは変えない。第7章のジンの本物のテルには触れない。
4. すべての案を、アニメーション込みで並べて見られる見本（Artifact）を作る。案が動きなら、全案が同時に動く短い動画（mp4）も作る。
5. ファイルは /mnt/project-files/research/ の下に置く。
6. 返信は日本語で短くする。原因、案の一覧（1行ずつ）、おすすめ、見本のリンクを書く。最後に、どれにするかを1語で答えられる形で聞く。
7. 案が決まったら、/mnt/project-files/research/<名前>_実装仕様.md に実装の手順を書き、ゲーム担当のスレッドへ渡す。
