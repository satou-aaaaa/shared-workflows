# LAST TELL 変更後チェックと公開

対象: /mnt/project-files/story/shisho.html（1ファイルのHTML）。担当は「ストーリーモードの企画提案」スレッド。

## 守ること
- 第1〜3章の難しさ（勝率）は変えない。第7章のジンの本物のテル（release）には触れない。
- 実際のお金でチップを売る仕組みは入れない。
- タイトルなどに「夜」という言葉を使わない。

## 手順
1. 変更前に shisho.html を読み直し、変更は小さく入れる。
2. 自動対戦（fuzz）を全モードで回す。章、フリー対戦（6人卓を含む）、裏の卓、一夜、日本語と英語。止まらないこと、チップの合計が合うことを確かめる。
   - テストでは設定を quiz:false にする。クイズの画面が出ると自動対戦が止まるため。
3. 第1〜4章の勝率を前の版と比べる。同じ範囲に入っていればよい。
4. 画面チェックをする。次の3つの大きさでスクリーンショットを撮る: スマホ縦 390x844、スマホ横 844x390、PC 1280x800。
   - 見る点: 重なり、画面からのはみ出し、手札・場札・ボタンが隠れていないか。
   - 画像は /mnt/project-files/story/ui-check/ に「v<版>_縦_390x844.png」のような名前で置く。
5. Artifact を同じリンクで新しい版として公開する（<この Artifact の URL>）。
6. 報告は日本語で短くまとめる。変わったこと、勝率、画面チェックの結果を1行（例「スマホ縦・横とPCで重なりなし」）、残っている問題を書く。
7. テスト公開版（https://satou-aaaaa.github.io/last-tell/）の更新は、「GitHub Pagesでテスト公開」スレッドに頼む。
