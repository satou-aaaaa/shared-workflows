# 論文問題の追加手順（天秤の書）

## 前提
- アプリは単体HTMLのArtifact（<この Artifact の URL>）。更新は必ず同じURLに新バージョンとして公開する。
- 論文試験中心。択一は補助。タイトル・本文に「法律事務所」「事務所」は使わない。
- 事案は実在判例ベースだが、人名・会社名は架空にする。過去問の文章はそのまま使わない。

## 1. 追加対象を決める
- 科目→分野ごとの問題数を数え、少ない分野から選ぶ（例：民訴の証拠、民法の相続、商法の株主総会）。
- 1回に追加するのは6〜10問程度。

## 2. 判例を一次資料で確認する（必須）
- 裁判所ウェブサイト（courts.go.jp）の裁判例検索で、裁判所・判決日・事件番号・掲載誌（民集・刑集の巻号頁）を確認する。
- 確認できない判例は使わない。その分野は見送り、理由を報告する。
- 二次資料しかない判例（大審院など）はその旨を注記する。
- 法改正で条文が変わっていれば、現行条文を引用欄に注記する（例：民法1014条2項・899条の2、会社法201条）。

## 3. 問題データを作る
各問題に以下をそろえる。
- 科目・分野・タイトル（短い日常語、例「知っていて買った山林」）
- 事例文（架空の名前）と設問
- 法的三段論法の観点：問題提起／規範／あてはめ／結論
- 模範答案と自己採点の観点（チェック項目）
- 目安時間
- 参考判例の引用（裁判所・日付・事件番号・掲載誌・裁判所ウェブサイトへのリンク）
- 規範カード（論点→規範）を1枚以上

## 4. 組み込みと確認
- 依頼一覧の科目→分野に正しく入ること、科目横の問題数表示が更新されることを確認。
- 全問で「答案作成→自己採点→Claude添削」を通しで動かし、エラーがないこと。
- スマホ幅とPC幅で、はみ出し・変な折り返しがないこと。
- 今日のメニュー（間隔反復）と規範カードの枚数に反映されること。

## 5. 報告
- 冒頭に「判断していただくことはありません」か、必要な判断を明示する。
- 追加した問題を「科目（分野）タイトル：論点（判例名・日付）」の形で列挙。
- 総問題数の変化、見送った分野と理由、次に手薄な分野を一言添える。
- ユーザーの確認が必要なものはプロジェクトチャットにも通知する。
