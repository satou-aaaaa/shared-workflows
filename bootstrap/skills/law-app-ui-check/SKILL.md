# UI点検の手順

## 1. 画面を一通り開く
- Playwright（プリインストールのChromium）で、スマホ幅（390px）とPC幅（1280px）のスクリーンショットを撮る。
- 対象：目次、答案画面、模範答案との比較、大問、ドリル、規範カード、新人研修、今日のメニュー、成績表示。

## 2. チェック項目
- コンソールエラーがないか。
- 横方向のはみ出しがないか（scrollWidth > clientWidth）。
- タップ領域が高さ44px以上か（折りたたみ見出し、チェック欄、リンク）。
- 目次がスマホで長すぎないか（画面何枚分か数える）。科目・分野で絞れるか。
- 正誤や選択状態が色と記号（✓/✗）の両方で分かるか。
- 表記の揺れ（「第1話」「判例ファイル」など）がないか。
- 長い見出し・設問文が不自然に折り返していないか。
- デザイン方針（六法全書：深緑・金箔・明朝体）から外れていないか。

## 3. 修正と再確認
- 見つけた点を直し、全問の通し動作と回帰テストを再実行する。
- 同じArtifact URLに新バージョンとして公開する。

## 4. 報告
- 冒頭で判断の要否を明示。
- 直した点を「問題：何をどう直したか（数値があれば前→後）」で列挙。
