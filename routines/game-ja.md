# ゲームの日本語の読み合わせ（週1・金曜 10:33 JST。新作の PR #1 でも）
<!-- style: v1 -->

先に `common.md` と `autonomy.md` を読むこと。（satou さんの依頼 2026-11-21「各ゲームで、選択肢や日本語がわかりづらいものがあるようです。これらを確認し、修正していってください」）

## 目的

ゲームの問題文・選び肢・ヒント・説明を、だれが読んでも1回で分かる日本語にする。正解が2つ取れる選び肢を残さない。機械で見られる所は `scripts/game-ja.mjs`（各ゲームの PR の QA「問題の日本語」）が見るので、ここでは機械で見られない所を読む。

## 考え方（調べた要点と出典）

- 一文は短く（目安 50〜60 字）、一文に一つのこと。二重否定・あいまいな言い方を避ける。専門用語には説明を添える。[文化庁「公用文作成の考え方」（2022 建議）](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93731901_01.pdf)・[出入国在留管理庁・文化庁「在留支援のためのやさしい日本語ガイドライン」](https://www.moj.go.jp/isa/support/coexistence/04_00004.html)
- 多肢選択は、正解を1つにし、選び肢どうしを重ねない（片方が正しければもう片方も正しい、を作らない）。「すべて」「どれでもない」を使わない。正解だけ長いなどの手がかりを作らない。否定でたずねるときは「ない」を目立たせる。[石井秀宗「テスト作成ガイドライン」（名古屋大学）](https://www.educa.nagoya-u.ac.jp/~ishii-h/materials/guidelines.pdf)
- 条文をそのまま見せると、「三月」（＝3か月）・「知つた」（＝知った）を読みちがえる。ヒントに条文を出すときは、意味を変えずに数字とかなを今の書き方にする（期限・日数のゲームの `lawPlain()`）。

## 使う道具

- `node scripts/game-ja.mjs <ゲームのフォルダ>`：機械で見られる所（✗ は直す・△ は読んで判断）
- `node scripts/game-ja.mjs --dump <ゲームのフォルダ>`：種類ごとに1問ずつ、問い・選び肢（◎が正解）・ヒント・説明を並べる（読み合わせ用）
- 台帳 [`ja-review.md`](../ja-review.md)：どのゲームをいつ読んだか
- 報告の返信・カード：Claude 以外は [tool-map.md](tool-map.md) の置き換え先

## 手順

1. shared-workflows を `git pull origin main` で新しくする。
2. 台帳 `ja-review.md` で「読んだ日」が空か、いちばん古いゲームを上から5本選ぶ。
3. 1本ずつ clone し、`node scripts/game-ja.mjs ../<ゲーム>` を回す。✗ があれば先に直す。
4. `node scripts/game-ja.mjs --dump ../<ゲーム>` を全部読み、下の「直すもの」の表に当たる所を書き出す。
5. 直す。問題の作り（`data.js`・`gen.js`）の言い回しは、乱数を引く数と順番を変えない（文字だけを変える）。
6. `qa/run.mjs` の `PIN` が選び肢の字を持っていて変わったら、PIN を新しい字にし、行の末に「日付 何を言いかえたか（並びは同じ）」を書く。
7. `node qa/run.mjs` を通す（同時に回すのは2本まで。メモリが足りず落ちる）。
8. PR を出す（[pr.md](pr.md)）。題は「日本語：<何を直したか>」。
9. 台帳の行に読んだ日と PR を書き、shared-workflows に PR を出す。
10. 機械で見つけられる形のまちがいが見つかったら、`scripts/game-ja.mjs` の RULES と `--self-test` の見本に足す。

## 直すもの

| もし | すること |
| --- | --- |
| 正解と、正解に条件を足しただけの選び肢がある（「取り消せる」と「1年たてば取り消せる」） | 条件の選び肢を、正解とも「できない」とも両立しないもの（「店が決める」など）に替える |
| 正解が2つに読める（言葉の範囲が重なる・「など」でどちらも当てはまる） | 問いに条件を足すか、選び肢を替える |
| 条文・専門用語をそのまま見せている | 言いかえを添えるか、`lawPlain()` を通す |
| 一文が 60 字をこえ、読みにくい | 2文に分ける |
| 助詞の抜け・重なり、不自然な言い回し | 直す |
| 否定でたずねる問いで「ない」が目立たない | 肯定の問いにするか、「ない」を太字にする |
| わざと元のまま見せる（憲法の条文を読む問題など） | `qa/ja-allow.txt` に「規則名<TAB>字の一部<TAB># 理由」を書く |
| どれにも当たらないが分かりにくい | 直す前に、なぜ分かりにくいかを PR の本文に1行書く |

## 完了条件

- 選んだ5本の ✗ が0（`node scripts/game-ja.mjs --strict ../<ゲーム>` が 0 で終わる）
- 5本の PR が出ている（直す所が無ければ台帳に「直す所なし」）
- 台帳の5行に読んだ日が入っている

## やってはいけないこと

- `KINDS`・言い回しの配列の並べ替え・削除（過去の日の問題が変わる）
- 答えの中身を、出典を読まずに変える（言い回しだけを直す。中身を変えるなら出典を読み直す）
- `qa/ja-allow.txt` に、直せるものを入れて ✗ を消す
