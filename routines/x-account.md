# X（@coedogameclub）の運用（週1・土曜 10:47 JST）

先に `common.md` と `autonomy.md` を読むこと。（satou さんの依頼 2026-11-04「Xの@coedogameclubアカウントで、宣伝もお願いします。また、ko-fiについても」「ゲームの遊び方等を投稿しても良いかもしれません」「アカウント運用agentを作って、そちらに依頼しても良いかもしれません」）

## 目的

小江戸ゲーム部の X（https://x.com/coedogameclub ）で、無料の Web ゲームを知ってもらう。毎週、次の1週間ぶんの投稿（1日1本）を X の予約投稿に入れておく。

## 考え方（調べた要点と出典）

- 本文に外部リンクがあると表示が伸びにくいと言われる。予約投稿には返信を付けられないので、リンクは本文の最後に1つだけ置く（コムニコ https://www.comnico.jp/we-love-social/x-algorithm ）。
- ゲームは遊んでいる画面が一番伝わる。投稿には必ず画面の画像を1枚付ける。決まった時間に続けて出す（Game Developer https://www.gamedeveloper.com/business/promoting-your-game-with-animated-gifs ）。
- 応援のお願いは、価値を渡したあとに、ときどき・1回だけ。何に使うか（新しいゲームづくり）を書く（Ko-fi ヘルプ https://help.ko-fi.com/hc/en-us/articles/360004392158 ）。
- プロフィールは自己紹介160字まで、固定ポストで一番見てほしい投稿を上に置く（X ヘルプ https://help.x.com/ja/managing-your-account/how-to-customize-your-profile ）。

## 使う道具

- Claude in Chrome（satou さんの PC の Chrome。X に @coedogameclub でログイン済み）。X の API・コネクタは無いので、投稿はこれでしかできない。ほかの AI・人は、satou さんがスマホの X アプリで予約する（下書きを渡す）。
- 計画と下書きの置き場：プロジェクトの共有フォルダ `x-promo/`（`plan.md`・`schedule.md`）。ほかの AI は tool-map.md の「共有フォルダ」の置き換え先。
- 報告：「Xでゲームを広める」スレッドへの message_thread（ほかの AI は tool-map.md の「スレッドへの返信」）。

## 手順

1. 節約モード（common.md）なら、手順2〜3だけして、下書きを共有フォルダに置き、報告して終える。
2. 共有フォルダ `x-promo/schedule.md` を読み、予約済みの最後の日を確かめる。
3. 次の7日（予約済みの最後の日の翌日から）の下書きを、決まりと話題の表どおりに作り、`x-promo/schedule.md` の末尾に足す。載せてよいゲームは次のとおり（`*.github.io` はクラウドから開けないので curl では確かめない。known-limits.md）。
   - Chrome が使えるとき：Chrome で `https://satou-aaaaa.github.io/<どれかのリポジトリ>/` を開き、javascript で `(await fetch('/<リポジトリ>/',{cache:'no-store'})).status` が 200 のものだけ。
   - Chrome が使えないとき：`x-promo/schedule.md` の表で前に「予約済み」「投稿済み」になったゲームだけ。
4. Chrome が使えるか確かめる：`tabs_context_mcp` を呼ぶ。
5. 下の表で分ける。

   | もし | すること |
   | --- | --- |
   | Chrome が使えて、x.com を開くと左下が「小江戸ゲーム部」 | 手順6へ |
   | Chrome が使えない・つながらない | 予約しない。手順10へ（下書きを satou さんに渡す） |
   | x.com がログイン画面・別のアカウント | 予約しない。手順10へ。報告に「X のログインが切れています」と書く |
   | どれにも当たらない | 止めて、Issue（ラベル needs-decision）に状況を書く |

6. 1本ずつ予約する（新しいタブを作って使う）：
   1. 画像用のタブでゲームのページを開き、遊び方などの画面を出して、縮めずにスクリーンショットを撮る（`scale` を付けると画質が落ちる）。
   2. X のタブで `https://x.com/compose/post` を開き、find で「本文の入力欄」「画像の file input」「ポストを予約」を探す。
   3. `upload_image` で画像を file input に入れる。
   4. 本文の入力欄を押して、本文を2〜3回に分けて入力する（一度に長く打つと文字が崩れたことがある）。
   5. 「ポストを予約」を押し、日・時・分の選択を `form_input` で選ぶ（月・年は確かめるだけ）。
   6. 「〇月〇日(〇)の午後〇:00に送信されます」の文を拡大して確かめてから「確認する」を押す。
   7. 「予約設定」を押し、4秒待つ。出てきたダイアログは「閉じる」だけを押す。
7. `https://x.com/compose/post/unsent/scheduled` を開き、予約の一覧に7本（Ko-fi の回があれば8本）が正しい日時で並んでいるか確かめる。
8. 画像用のタブを閉じる。
9. `x-promo/schedule.md` の各行に「予約済み」と書く。
10. 「Xでゲームを広める」スレッドに報告する（下の「報告」）。

## 完了条件

- `x-promo/schedule.md` に次の7日ぶんの下書きがある。
- Chrome が使えた回：予約の一覧に、その7日ぶんが正しい日時で入っている（手順7で確かめた）。
- Chrome が使えなかった回：satou さんへの報告に、コピーしやすい下書きと「やること」がある。

## 報告

- 予約できた回：1〜3行（予約した日と話題、Ko-fi の回の有無）。
- 予約できなかった回：先頭に「satouさんにお願い：」。「Chrome を開いて Claude の拡張をつないでください」と、本文1本ずつをコードの枠に入れて渡す（スマホの X で予約する用）。

## やってはいけないこと

- お笑いの要素を入れない（2026-11-03 satou さん「変にお笑い要素が入っている」）。本物っぽく、普通の言葉で。
- 答え（株の会社名とニュースの結果、今日の問題の正解など）を書かない。今日の問題を satou さんの Chrome で解かない（satou さんの記録が変わる）。タイトル・遊び方・レベル1の画面だけ使う。
- 広告（有料のプロモーション）・有料プラン（Premium など）を使わない。
- X の「人間か確認」「より多くの機能を利用する」などの画面は、「閉じる」以外を押さない。パスワード・電話番号・カード番号を入れない。
- 個人情報（本名・住所・メール）を書かない。
- 他人の投稿へのリプライ・いいね・フォローを大量にしない（スパム扱いを避ける）。返信は自分の投稿へのものにだけ、1日5件まで。
- プロフィール（名前・画像・自己紹介）は、ゲームが増えた・減ったときだけ直す。
