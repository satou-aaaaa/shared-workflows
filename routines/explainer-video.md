# 合成音声の掛け合い解説動画を作る（新しい回を作るたび）
<!-- style: v1 -->

## 目的
VOICEVOX などの合成音声で作る解説動画（長尺 4〜9 分）を、YouTube の「量産型のコンテンツ」（2025-07-15 改名、2026-07-16 に説明を細分化）と判定されにくく、最初の 30 秒で離れられにくい形で毎回同じように作る。
根拠と出典は、プロジェクトの共有フォルダ `youtube/research_2026-11-25/解説動画が伸びるコツ.md`。

## 使う道具
- 台本テンプレ：共有フォルダ `youtube/tools/解説_台本テンプレ.md`（台本の頭に「型」「作者の目線」「結論の予告」の欄）
- 使い回し検査：`python3 youtube/tools/reuse_check.py <回>/narration.json --author <作者の目線のslide名>`（クラウド側。結果は `reuse_check.json`）
- 組み立て：`build_explainer.py spec.json`（PC 側。オープニング 2.5 秒・エンディング 15 秒・概要欄に再生リストと制作の関与の行）
- 公開前の判定：`gate_explainer.py spec.json`（PC 側。I の項目がこの手順の決まり）
- 共有フォルダ（`/mnt/project-files`）は [tool-map.md](tool-map.md) の置き換え先を使う

## 手順
1. 台本をテンプレの形で書く。頭の欄に、型（a 問い→実験 / b 事件→謎解き / c ランキング・くらべ / d 失敗談→学び）・作者の目線の中身・結論を予告する行の番号を書く。
2. 表紙の 1〜2 行目で、タイトルの約束（結論の予告）を言い切る。茶番は結論の予告のあとに置く。
3. 「作者の目線」の章を 450 字以上（約 60 秒）にする。作者自身の体験・自作ゲームでの試し・自分で計算した数字を書く。
4. 最後の 1 行を次の回の予告にする。
5. 台本から narration.json を作る（各シリーズの md2json）。
6. クラウドで `reuse_check.py` を実行する。NG なら下の分岐表に従う。
7. `reuse_check.json` を PC の作業フォルダへコピーする。`reuse_check.py` は `gate_explainer.py` と同じフォルダに置く。
8. spec.json に `kata`（a〜d）・`hook`（結論を予告する行の番号、1 から）・`author_slide` を書く。シリーズの再生リストがあれば `playlist_url` も書く。
9. 音声を作り、`build_explainer.py` を実行する。
10. `gate_explainer.py` を実行する。NG があればアップロード・予約に進まない。
11. 公開予約のあと、終了画面に「次の回（または最新の動画）」と「シリーズの再生リスト」の 2 つを置く。
12. 長尺 1 本ごとに縦ショートを 1 本作り、関連動画リンクをその長尺にする。ショートの公開は長尺の翌日以降。

## 迷ったとき

| もし | すること |
| --- | --- |
| reuse_check が「使い回し 15% 超え」 | 出た文（hits）を言い換える。わざと毎回言う決めゼリフなら `REUSE_OK` に理由つきで足す |
| reuse_check が「作者の目線が短い」 | 作者の体験・数字を足す。水増しの言い換えで伸ばさない |
| gate の I「結論の予告が遅い」 | 表紙の茶番を結論の予告のあとへ動かす。spec の hook の番号を直す |
| 2026-11-25 より前に台本ができた回 | 作り直さない。spec に `"growth_rules_exempt": "11/25 以前に作成"` と書く（I は注意だけになる） |
| 法律・お金・健康の回 | キャラに個別の助言をさせない（「判決ではこう判断された」の形）。概要欄に「一般的な説明です。個別の相談は専門家へ」 |
| どれにも当たらない | 止めて、プロジェクトのチャットに状況を書く |

## 完了条件
- `reuse_check.json` の ratio が 0.15 以下で、作者の目線が 60 秒以上（gate の I が音声の長さで確かめる）
- `gate_result.json` が ok（I を含む全項目）
- 終了画面 2 つとショートの関連動画リンクが Studio で設定済み

## やってはいけないこと
- 同じ台本の言い回しを回をまたいでコピーしない（使い回し検査を通すための文字いじりもしない）
- 作者の目線の章を他の回から写さない
- `growth_rules_exempt` を 2026-11-25 以後に作る回に書かない
- 予約時刻を変えない（長尺 20:00、ショート 12:00・15:30・19:00。変えるのは夜のアナリティクスの提案を作者が選んだときだけ）
